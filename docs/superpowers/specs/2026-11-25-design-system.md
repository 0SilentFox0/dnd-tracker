## 1. Принципи

1. **Статистика — основа.** Це гра D&D. Хіти, КЗ, ініціатива, швидкість і шість характеристик з рятунками видно без прокрутки й без вкладок на будь-якому ноутбуці (1280×800). Історія, інвентар, журнал — другий рівень.
2. **Клікаєш число — кидаєш кубик.** Будь-яке число, яке в грі кидають (перевірка, рятунок, навичка, влучання, шкода), є кнопкою. Результат приходить одразу, без переходів.
3. **Один колір крові.** Палітра: вугілля, кістка, один багряний. Багряний означає «дія, володіння, хіти, дім Харконідів» і більше нічого.
4. **Зроблено руками, а не згенеровано.** Фактура зерна, орнамент, гравіровані рамки, професійні ігрові іконки. Ніякого сяйва, неонових акцентів і градієнтних плям.
5. **Форма несе сенс, колір підсилює.** Володіння показує заповнений ромб, а не лише колір. Стан хітів показує мітка, а не лише відтінок шкали.
6. **Нічого не стрибає.** Перемикання вкладок, кидки, зміна хітів не зсувають сторінку під пальцем.
7. **Однаково для обох палітр.** Таверна (темна) і Пергамент (світла) — це та сама ідея вдень і вночі. Кожен компонент перевіряється в обох.

## 3. Фундамент

### 3.1 Кольори

Дві палітри, перемикаються атрибутом `html[data-palette="tavern|parchment"]`. Значення за замовчуванням — `tavern`.

#### Токени

| Токен | Роль | Таверна | Пергамент |
|---|---|---|---|
| `--page` | фон сторінки | `#111013` | `#e9e1d1` |
| `--panel` | поверхня панелі | `#18161a` | `#f1ebdf` |
| `--panel-2` | піднята поверхня: кнопки, активна вкладка, hover | `#1e1b20` | `#f8f4ec` |
| `--inset` | заглиблення: поля, шкали, жетони | `#0a090b` | `#dbd0bc` |
| `--ink` | головний текст, числа | `#ece4d6` | `#1e1711` |
| `--text` | основний текст | `#c8beaf` | `#3a2f25` |
| `--muted` | другорядний текст, підписи | `#8b8277` | **`#64584b`** (було `#73675a`, див. 8.2) |
| `--faint` | **лише декор**: розділові «·», шеврони, неактивні іконки поруч із підписом | `#5b554e` | `#a29482` |
| `--line` | тонкі розділювачі | `rgba(236,228,214,.08)` | `rgba(55,38,20,.12)` |
| `--line-strong` | рамки контролів | `rgba(236,228,214,.17)` | `rgba(55,38,20,.25)` |
| `--hi` | внутрішній блік верхнього краю | `rgba(255,255,255,.05)` | `rgba(255,255,255,.75)` |
| `--crimson` | заливка: основна кнопка, стяг, мітки володіння | `#b3312c` | `#a12b28` |
| `--crimson-2` | тінь багряного, кант кнопки, низ стягу | `#7c1e1d` | `#761d1b` |
| `--crimson-fg` | **новий**: багряний текст і іконки на темних поверхнях | **`#e0604f`** | `#a12b28` |
| `--crimson-ink` | текст на багряному | `#fbefe9` | `#fff4ef` |
| `--hp` | шкала хітів, іконка серця | `#c8382f` | `#b0332a` |
| `--hp-2` | низ градієнта шкали | `#8a211c` | `#84231d` |
| `--sh` | тінь панелі | `0 1px 2px rgba(0,0,0,.5), 0 16px 36px -18px rgba(0,0,0,.9)` | `0 1px 2px rgba(70,45,20,.12), 0 14px 32px -20px rgba(70,45,20,.45)` |
| `--sh-btn` | тінь кнопки | `0 1px 0 rgba(0,0,0,.55), 0 4px 10px -4px rgba(0,0,0,.7)` | `0 1px 0 rgba(70,45,20,.2), 0 4px 10px -5px rgba(70,45,20,.35)` |
| `--grain-op` / `--grain-mode` | фактура | `.32` / `overlay` | `.5` / `multiply` |

#### Семантика

- **Багряний** (`--crimson`, `--crimson-fg`) означає лише: головну дію (одна на екран), володіння (ромби, сегменти навичок), основну характеристику, бонус майстерності, активну вкладку, стяг дому. Не використовувати для «гарно».
- **Хіти** (`--hp`) — окремий токен, навіть якщо зараз близький до багряного. Колір хітів може змінитися незалежно.
- **Немає зеленого, синього, жовтого.** Для майбутніх станів (отрута, благословення тощо) — форма й іконка, а не новий колір. Новий колір додається лише через рев'ю дизайн-системи.
- **Стани помилки/успіху** у грі: успіх = `--ink` + форма (заповнений ромб), провал/небезпека = `--crimson`.

#### Ієрархія поверхонь

```
page  →  panel  →  panel-2 (піднято: кнопка, активне)
           ↘ inset (заглиблено: поле, шкала, жетон)
```

### 3.2 Типографіка

| Сімейство | Роль | Накреслення | Чому |
|---|---|---|---|
| **Cormorant SC** | заголовки, ім'я, назви характеристик, лейбли | 700 | Різана класична капітель, як у фентезі-RPG; повна кирилиця |
| **Alegreya** | текст, історія, кнопки, підказки | 400, 500, 700, 400 italic | Книжкова антиква для довгого читання, тримає кирилицю |
| **Oswald** | усі числа HUD, модифікатори, значення | 500 | Вузький «табло»-шрифт: великі цифри займають мало місця |

Підключення: Google Fonts, `display=swap`, `preconnect` на обидва домени. Фолбеки: `Georgia, serif` / `"Arial Narrow", sans-serif`.

`font-variant-numeric: lining-nums tabular-nums` на `body` — числа однакової ширини, не скачуть при зміні хітів.

| Токен (рекомендований) | Розмір / висота | Сімейство | Де |
|---|---|---|---|
| `display` | `clamp(40px, 4.4vw, 60px)` / .95 | Cormorant SC 700 | ім'я героя |
| `stat-xl` | 52px / 1 (телефон 40) | Oswald 500 | модифікатор характеристики |
| `stat-l` | 46px / 1 (≤1100: 40, телефон 34) | Oswald 500 | ініціатива, швидкість |
| `stat-m` | 27–34px / 1 | Oswald 500 | хіти в шкалі, КЗ у щиті, пасивні |
| `title-l` | 28px / 1.05 | Cormorant SC 700 | заголовок вікна |
| `title-m` | 24px / 1 | Cormorant SC 700 | заголовок блоку («Характеристики») |
| `title-s` | 19–20px | Cormorant SC 700 | назви характеристик, груп навичок, рядок «хто» |
| `label` | 17px / 1.1 | Cormorant SC 700 | підписи HUD |
| `body-l` | 19px / 1.7 | Alegreya 400 | текст історії |
| `body` | 16–17px / 1.5 | Alegreya 400–500 | інтерфейс |
| `small` | 14–15px | Alegreya 400 | пояснення, мета |
| `micro` | 13px | Alegreya | **мінімум**; лише другорядне |

Правила:
- Нічого менше 13px. Інтерактивний текст не менше 15px.
- `text-wrap: balance` для імені й заголовків.
- Курсив лише для одного рядка-вступу і цитат в історії.
- Капітель Cormorant SC замінює UPPERCASE. `letter-spacing` у лейблів не збільшуємо.

| Відступ вікна | 22 (телефон 16) |
| Між блоками на сторінці | 24–28 |

### 3.4 Радіуси

| Токен | Значення | Де |
|---|---|---|
| `--r` | **4px** | усе: панелі, кнопки, поля, тости, вікна |
| — | 3px | елементи всередині контейнера (активна вкладка, сегмент перемикача) |
| — | 2px | заповнення шкал, ромби |
| — | 0 | стяг (вирізаний clip-path), лінії |

Більше 6px не використовувати. Кола (`50%`) не використовуються.

### 3.5 Глибина (elevation)

| Рівень | Що | Реалізація |
|---|---|---|
| −1 заглиблення | поля, шкали, жетони, щит КЗ | `background: var(--inset)` + `inset 0 1px 3px rgba(0,0,0,.4–.55)` |
| 0 площина | сторінка, вміст вкладок | без тіні |
| 1 панель | HUD, характеристики, списки | `var(--panel)` + `inset 0 1px 0 var(--hi)` + `var(--sh)` |
| 2 контрол | кнопки, активна вкладка | `var(--panel-2)` + `inset 0 1px 0 var(--hi)` + `var(--sh-btn)`; при натисканні `translateY(1px)`, тінь зникає |
| 3 оверлей | вікна, тости, підказки | `var(--panel)`/`--panel-2` + `0 30px 80px -24px rgba(0,0,0,.9)` |

Основна кнопка: заливка `--crimson`, кант `--crimson-2`, внутрішній блік зверху `rgba(255,255,255,.2)` і тінь знизу `inset 0 -2px 0 rgba(0,0,0,.2)` — «кнопка, яку натискають».

### 3.6 Фактура й патерни

Патерни — «трішки». Кожен має одне місце.

| Патерн | Де | Реалізація | Правило |
|---|---|---|---|
| Зерно | `body::before`, на всю висоту документа | SVG `feTurbulence`, `opacity: var(--grain-op)`, `mix-blend-mode: var(--grain-mode)`, `position: absolute` (не `fixed`: інакше обрізається на скріншотах і друку) | Не на окремих компонентах |
| Ромбова решітка | лише стяг | SVG-плитка 26×26, ромб + крапка, alpha ≈ .08/.13 | Тільки на багряному |
| Орнаментальний роздільник `.orn` | під заголовком «Характеристики», у заголовках вікон | `mask` зі SVG-плиткою (лінія–ромб–лінія), колір `--line-strong` | Не більше одного на блок |
| Кутові накладки `.ornate` | HUD, характеристики, вікна | `::after` з 8 лінійними градієнтами 16×2px, колір `color-mix(--muted 70%)` | Лише ключові панелі; не на кожну |
| Поділки шкали | шкала хітів | `repeating-linear-gradient` кожні 10% | Лише на шкалах з числом |

Патерни, що беруть колір з токенів, робляться через `mask-image`, а не через колір у data-URI: тоді вони перефарбовуються з темою.

### 3.8 Рух

| Токен | Значення | Де |
|---|---|---|
| `--ease` | `140ms ease` | колір, рамка, фон на hover |
| — | `120ms` | поява підказки |
| — | `160ms ease` | поява вікна (`translateY(10px) scale(.98)` → 0) |
| — | `180ms ease` | поява тоста |
| — | `300ms ease` | зміна ширини шкали хітів |

Одна осмислена анімація на подію. Нічого не «дихає» і не пульсує. `prefers-reduced-motion: reduce` вимикає всі переходи й анімації.

| Шар | z-index |
|---|---|

| Вікна | top layer (`<dialog>.showModal()`) |

## 4. Сітка й композиція

| Назва | Ширина | Що змінюється |
|---|---|---|
| desktop | > 1100 | стяг 200px + основна колонка; HUD у рядок 1.5 : .55 × 3 |

64×44, Oswald 20px, `--inset`, рамка `--line-strong`, фокус — рамка `--crimson`. `inputmode="numeric"`. Enter у полі хітів = «Шкода» (найчастіша дія).

Висота 56. Ліворуч: іконка `tower` (`--crimson`) + крихти. Праворуч: група «Майстер» (лейбл + «Редагувати», «Ресурси») і перемикач палітри. На телефоні крихти й лейбл сховані, дії майстра стають іконками з `aria-label`.

### 5.4 Перемикач палітри `.pal`

Сегменти-іконки (місяць/сонце) в заглибленні `--inset`; активний сегмент піднятий. `role="group"`, кнопки з `aria-pressed` та `aria-label` («Таверна», «Пергамент»). Неактивна іконка — `--muted` (не `--faint`, див. 8.2).

### 5.5 Стяг і портрет `.banner` / `.frame` / `.plate`

- Стяг: 200×340 (tablet 170×300, телефон 104×176), `clip-path` з «ластівчиним хвостом», заливка `--crimson → --crimson-2`, бічні тіні, ромбова решітка, внутрішня кант-лінія.

- Табличка рівня `.plate`: число Oswald + «рівень» капітеллю, на нижньому краї рамки.
- Герб `tower` унизу стягу (на телефоні прихований).
- Портрет: `<img alt="Портрет …">`, `object-fit: cover`. Поки нема зображення, показуємо **монограму** (ініціали Cormorant SC, alpha .1). Якщо зображення не завантажилось, `onerror` прибирає `<img>` і лишається монограма.

### 5.6 Блок ідентичності `.intro`

Рядок «хто» (клас багряним, решта через «·», кожен пункт `nowrap`, переноси між пунктами) → ім'я (`display`) → вступ один рядок курсивом + `link--strong` «Історія». На tablet і телефоні вступ ховається.

### 5.7 CTA розподілу `.cta`

Текст «+N очок / розвитку» + основна кнопка «Розподілити» з іконкою `up`. Відкриває вікно 5.20. Коли очок 0: «Усі очки», кнопка `disabled`, блок притишений (opacity .55). Видно лише гравцю-власнику й майстру.

### 5.8 HUD `.hud` (panel + ornate)

Сітка: хіти 1.5fr | 3 показники по .55fr; нижній рядок — підпоказники й «Відпочинок».

**Хіти:**
- Заголовок: іконка серця `--hp` + «Хіти» + мітка стану (5.9) ··· «Тимчасові N» + міні-кнопка «+».
- Шкала `.hpbar` 42px: заглиблення, заливка з бліком згори, поділки по 10%, число всередині ліворуч (Oswald 27px, `#fff4ef` з тінню). `role="meter"`, `aria-valuemin/max/now`, **додати `aria-valuetext="274 з 274"`**.

**Показники:**
- Захист: іконка + підпис, значення у **щиті** `.ac` (SVG-контур 60×68, `--inset`, число Oswald 32px). Щит — конвенція D&D, його шукають першим.
- Ініціатива, Швидкість: іконка над підписом, число 46px; одиниця «фт» 18px `--muted`.

**Підпоказники `.hud__sub`:** Майстерність (значення `--crimson-fg`), Влучання, Кістки хітів `N/M к6`, Пас. уважність; праворуч «Відпочинок» (іконка `camp`). Кожен підпоказник має підказку (5.25). На телефоні сітка 2×2 і «Відпочинок» на всю ширину.

### 5.11 Перемикач режиму кидка `.mode`

Три сегменти: «Звичайний», «Перевага», «Перешкода». Активний піднятий, а перевага/перешкода додатково мають нижню риску (`--ink` / `--crimson`), тож стан видно не лише кольором. `role="radiogroup"`, кнопки `role="radio"` + `aria-checked`. ### 5.13 Вкладки `.rail` (tablist)

- Активна: `--panel-2`, блік, жирний текст `--ink`, іконка `--crimson-fg`, риска 2px знизу.

- Поведінка без стрибків — розд. 6.5.
- Порядок: **Навички** (за замовчуванням) · Бій · Магія · Інвентар · Риси · Історія · Журнал.

### 5.14 Група навичок `.sg` і рядок навички `.sk`

### 5.16 Рядок атаки `.attack`

`[слот-іконка 56] Назва (кнопка-посилання) / мета ··· [влучання +11] [шкода 1к8+5]`.
- Назва відкриває картку 5.22; підкреслення з'являється на hover.
- Мета: тип · дальність · вид шкоди. **Кубики шкоди не дублюються в меті** — вони в кнопці.
- Телефон: слот 44, кнопки 60/70, підписи в кнопках сховані.

### 5.17 Стан і рятунки від смерті

- Рядки «Стани», «Виснаження».
- Рятунки: дві групи по три ромби-кнопки `aria-pressed`. Успіх заповнюється `--ink`, провал — `--crimson`. Три успіхи: тост «Стабілізований»; три провали: тост «Загинув» (crit-стиль). Довгий відпочинок скидає.

### 5.18 Комірки заклять `.slots`

- 9 колонок (телефон 5+4), римські номери рівнів Cormorant SC.
- Кожна комірка — ромб-кнопка 15px: доступна — заливка `--ink`; витрачена — порожня обвідка `--faint`. `aria-pressed` = витрачена, `aria-label` «Комірка N рівня[, витрачена]».
- Клік витрачає наступну доступну, клік по витраченій повертає одну; тост «Лишилось X з Y».

### 5.19 Список / риса `.list`, `.item`

Рядок 68px: слот-іконка 46 + назва/підпис + праворуч кількість або шеврон. Риси — кнопки, що відкривають картку 5.22.

### 5.20 Вікно `dialog.modal` (база)

- Нативний `<dialog>` + `showModal()`: фокус-пастка, Esc і top layer з коробки.
- Ширина `min(560px, 100vw − 24px)`, висота ≤ `100vh − 32px`, тіло прокручується.
- Анатомія: заголовок (іконка 34 `--crimson-fg`, назва `title-l`, підзаголовок `small`, «×») → `.orn` → тіло → футер (вторинне ліворуч, «Скасувати», основна праворуч).
- Закриття: «×», «Скасувати», Esc, клік по підкладці.
- `aria-labelledby` на заголовок.
- Backdrop `rgba(6,5,7,.72)` + blur 2px.

### 5.21 Вікно «Розподіл очок» `#dlg-levelup`

- Лічильник «Залишилось очок» (Oswald 34) у заглибленні.
- Рядок на кожну характеристику: іконка · назва · `13 → 15` (нове значення багряне, якщо змінилось) · `[−][+]` · новий модифікатор.
- «−» вимкнено, якщо в цій характеристиці нічого не додано; «+» вимкнено, коли очок 0 або значення 30.
- «Скинути» (посилання), «Скасувати», «Застосувати» (вимкнено, поки нічого не розподілено).
- Застосування перераховує характеристики, рятунки й навички; тост «Розподілено N очок».
- Фокус лишається на тій самій кнопці після перерендеру рядків.

### 5.22 Картка атаки / риси `#dlg-card`

Заголовок з іконкою і типом («Замовляння · школа втілення»), мета-рядок (`значення` + `підпис`), опис, кнопки кидка «Влучання +11» / «Шкода 4к10». Результат кидка приходить тостом **над** вікном.

### 5.23 Вікно «Відпочинок» `#dlg-rest`

Підзаголовок з поточними хітами й кістками. Дві опції-картки:
- **Короткий** (`hourglass`): поле «скільки кісток» + «Витратити». Лікування = Σк6 + Статура × N. Якщо кісток нема — тост з поясненням.
- **Довгий** (`camp`): «Відпочити» (основна). Правила — розд. 6.3.

### 5.24 Тост результату `.toast`

- Позиція: знизу по центру, ширина ≤ 420; максимум 3 одночасно; живе 4.2 с.
- `[іконка] Назва / деталі ··· ПІДСУМОК`. Підсумок Oswald 34.
- Деталі кидка: `к20: 15 + 11`, `Перевага 8 і 1 → 8 + 5`, `4к10: 3 + 9 + 2 + 7`.
- Критичний (нат. 20 або 1, загибель): рамка й підсумок `--crimson` + текст «критичний успіх/провал».
- Контейнер `popover="manual"`, перевідкривається на кожен тост, щоб бути над вікном. `aria-live="polite"`.

### 5.25 Підказка `.tip`

- Одна на сторінку, `position: fixed`, над елементом (якщо не влазить — під ним), притиснута до країв вікна.
- Показ: наведення мишею (не на дотик), фокус з клавіатури (`:focus-visible`). Ховається при виході курсора, втраті фокусу, прокрутці, натисканні.
- Текст ≤ 2 рядки, пояснює **як рахується** число. Підказка — доповнення: ключова інформація не може жити лише в ній.
- Вимоги WCAG 1.4.13 — розд. 8.6.

### 5.26 Історія (кодекс)

Колонка ≤ 860. Розділ: римський номер (Cormorant SC 44 `--crimson-fg`, вирівняний праворуч у колонці 96px) + назва + абзаци `body-l`. Між розділами — цитата курсивом 28px з підписом-джерелом. Без плашок, буквиць і таймлайнів.

### 5.27 Орнаменти

`.orn` і `.ornate` — розд. 3.6. Обидва `aria-hidden`/декоративні.

## 6. UX-патерни й правила взаємодії

### 6.1 Кидки

- Будь-що з `data-roll` кидає кубик. Вираз: `+N`/`−N` = к20 + модифікатор; `XкY±Z` = кубики шкоди.
- Режим (6.1.1) діє лише на к20.
- Натуральна 20 / 1 — критичний успіх/провал, позначається в тості.
- Кидок ніколи не змінює стан листа автоматично (шкода від кидка не віднімається від цілі — це інша сутність).

**6.1.1 Перевага/перешкода:** кидаються два к20, береться більший/менший, у тості видно обидва. Режим лишається, доки гравець не перемкне (не скидається після кидка) — так за столом зазвичай кидають серію з перевагою.

### 6.2 Хіти

Порядок застосування шкоди:
1. Спершу списуються **тимчасові** хіти.
2. Залишок — з поточних, не нижче 0.
3. На 0 — стан «Без тями», тост про рятунки від смерті.

Лікування: не вище максимуму, тимчасові не змінює.
Тимчасові: **не сумуються**, лишається більше значення (правило 5e); тост це пояснює.

### 6.3 Відпочинок

| | Короткий | Довгий |
|---|---|---|
| Хіти | +Σк6 + Статура × N | до максимуму |
| Тимчасові | без змін | 0 |
| Кістки хітів | −N | +половина від максимуму (мін. 1), не вище максимуму |
| Комірки заклять | без змін (Магічне відновлення — окрема дія, TODO) | усі повертаються |
| Рятунки від смерті | без змін | скидаються |

### 6.4 Розподіл очок

Очки розвитку платформи (не правило 5e): 1 очко = +1 до значення, стеля 30. Чернетка живе у вікні, нічого не змінюється до «Застосувати». Скасування не зберігає чернетку.

### 6.5 Вкладки: алгоритм без стрибків

```
при кліку на вкладку:
  stuck = tabs.top ≤ 1px            // панель прилипла
  показати панель, оновити aria-selected, roving tabindex
  прокрутити рядок вкладок так, щоб активна була по центру (горизонтально)
  history.replaceState(#tab)
  якщо stuck → прокрутити сторінку так, щоб вміст починався одразу під панеллю
  інакше      → нічого не прокручувати
посилання «Історія» з шапки → плавно прокрутити до панелі вкладок
```
Панелі мають `min-height: calc(100vh − 80px)`, щоб коротка вкладка не «підтягувала» сторінку і панель не відлипала.

Стан вкладки: `#hash` у URL (`#combat`, `#magic`…), відновлюється при оновленні. Підтримується також `?tab=` для превʼю.

## 7. Контент і мова

- Мова: українська; `lang="uk"` на `<html>`.
- Регістр: речення з великої літери; капітель дає шрифт, а не CAPS LOCK.
- Тон: коротко, по-ігровому, без канцеляриту. Підказки пояснюють правило одним реченням.
- **Мінус**: типографський `−` (U+2212) у модифікаторах і кнопках; дефіс лише в словах.

- **Одиниці**: `30 фт` (у HUD «фт» дрібніше, без пробілу візуально).
- **Знак модифікатора** завжди: `+0`, `+5`, `−1`.
- **Дробі**: `274 / 274` у хітах (пробіли), `20/20 к6` у кістках (без пробілів).
- Числа в таблицях і HUD — Oswald, табличні.
- Тестовий/приклад-текст позначається один раз дрібним рядком «Приклад тексту для прототипу» (колір `--muted`).

### 8.2 Обов'язкові виправлення кольору (у межах міграції)

1. Додати `--crimson-fg` і використовувати його для **всього багряного тексту й іконок** на темних поверхнях: рядок «хто», «+6» майстерності, номери розділів історії, іконка основної характеристики, іконки заголовків вікон, активна іконка вкладки, бренд у topbar. Заливки (кнопка, стяг, ромби, сегменти) лишаються `--crimson`.
2. Пергамент: `--muted: #64584b`.
3. `--faint` **заборонено** для тексту і для іконок, які є єдиним носієм сенсу. Перевести на `--muted`:
   - `.dm__label` «Майстер»
   - `.pal button` (неактивна іконка — це кнопка без тексту)
   - `.sample` «Приклад тексту…»

### 8.3 Фокус

- `:focus-visible { outline: 2px solid var(--crimson); outline-offset: 2px }` — на багряному тлі (основна кнопка) кільце губиться. **Замінити** на подвійне кільце з токена:
  `--focus: 0 0 0 2px var(--page), 0 0 0 4px var(--ink);` → `box-shadow: var(--focus)` (контраст ≥ 3 у будь-якому контексті).
- Фокус не ховається під sticky-вкладками: `scroll-padding-top: 72px` на `html`.
- Порядок табуляції = візуальний порядок (topbar → CTA → HUD → режим кидка → характеристики → вкладки → вміст).

- `prefers-reduced-motion` вимикає всі переходи (є).

## 9. Дані й формули

| Величина | Формула | Примітка |
|---|---|---|
| Модифікатор | `floor((значення − 10) / 2)` | |
| Рятунок | `модифікатор + (володіння ? майстерність : 0)` | ІНТ: 5 + 6 = +11 ✔ |
| Навичка | **зараз**: `модифікатор`; **за правилами 5e**: `модифікатор + (володіння ? майстерність : 0)` | ⚠ див. нижче |
| Пасивна навичка | `10 + навичка` | Уважність = 10 + Сприйняття |
| Атака закляттям | `ІНТ + майстерність` = +11 ✔ | |
| СК заклять | `8 + ІНТ + майстерність` = 19 ✔ | |
| Короткий відпочинок | `Σ Nк6 + Статура × N` | |
| Кістки після довгого | `min(max, поточні + max(1, floor(max / 2)))` | |

### Відомі проблеми вихідних даних

1. **Навички з володінням не мають бонусу майстерності.** Магія показує +5, має бути +11; пасивні (14/14/15) теж рахуються без нього. У прототипі формулу свідомо лишено, як у даних. Виправлення — одна формула в моделі; UI перерахується сам.
2. **Ініціатива 12.** За правилами це модифікатор Спритності (+2) плюс бонуси. Схоже на «10 + 2». Перевірити джерело.
3. **КЗ 13 без обладунків.** 10 + СПР = 12; +1 може бути від предмета. Показувати джерело бонусів у підказці.
4. Скорочення «ТІЛ» vs назва «Статура» (розд. 7).

### 11.3 Фази

1. **Токени й база** (1 PR): `tokens.css`, шрифти, зерно, фокус-кільце, виправлення контрасту 8.2. Без змін розмітки. Скріншот-тести обох палітр.
