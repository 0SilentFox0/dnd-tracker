# Автотеги в редакторі сценарію — дизайн

ТЗ: `docs/superpowers/plans/2026-11-27-scenario-auto-mentions-prompt.md` (рішення власника 2026-11-27).

## Мета

Текст сценарію, що збігається з назвою сутності бібліотеки, стає згадкою (`mention` `{ type, id, label }`) без набору `@`:

1. **Наживо** — щойно завершене слово/фраза (після пробілу, розділового знака або Enter) перетворюється на чип; Ctrl+Z повертає звичайний текст.
2. **Кнопка «Тегнути збіги»** в тулбарі редактора — проходить усі рядки сторінки (story + notes), зокрема вже написані.

## Що перевикористовується

- `lib/utils/scenario/wrap-mentions.ts` — обхід `RichDoc` з обгортанням збігів у чипи (злиття текстових вузлів, спільні marks, наявні чипи не чіпає). Зараз приймає одну ціль; узагальнюю внутрішній `wrapRun` до резолвера «збіг → ціль | null», `wrapMentions` лишається тонкою обгорткою (поведінка й тести без змін).
- `escapeRe` з `lib/utils/scenario/mentions.ts`.
- `lib/server/scenario/mentions.ts` — запити по типах; додаю поруч функцію повного списку імен.
- `scenarioKeys` (новий ключ `mentionNames`), `campaignGet` у `lib/api/scenario.ts`, `requireDM`/`handleApiError`.
- `useToasts` (`lib/hooks/common`) для результату кнопки; `HudButton` у тулбарі.

Нове потрібне лише для: індексу імен (одного запиту на сесію редактора), чистого матчера, TipTap-розширення для живого режиму.

## Джерела

`unit`, `artifact`, `character` (лише `ACTIVE_CHARACTER`), `acquaintance`. Spell/battle/marker не входять: SRD-заклинання на кшталт «Щит», «Світло» дають хибні збіги на звичайних словах; їх і далі тегають вручну через `@`.

## Правила збігу (чиста функція)

`lib/utils/scenario/auto-mentions.ts`:

- `buildAutoMentionIndex(options: MentionOption[]): AutoMentionIndex`
  - відкидає назви коротші за 3 літери (після trim);
  - відкидає **неоднозначні** назви: та сама назва (порівняння без урахування регістру) у більш ніж однієї сутності — будь-якого типу, включно з двома юнітами з однаковою назвою;
  - будує один regex з альтернатив, довші назви першими.
- Шаблон назви: кожне слово = точне слово + закінчення `\p{L}{0,3}`; слова фрази розділені `[\s ]+`. Регістр нечутливий **лише для першої літери фрази** (`[Зз]ехір`), решта — точно. Межі: перед збігом не літера/цифра/`_`/`@`, після — не літера/цифра/`_`.
  - Розширення правила «назва + 1–3 літери» (погоджено власником 2026-11-27): якщо слово ≥ 4 літер і закінчується на `а я о е є й ь`, ця одна голосна може замінюватися закінченням (Ізабелла → Ізабелли/Ізабеллою, Гоголь → Гоголя). Без цього жіночі імена на -а не тегаються у непрямих відмінках.
- Розв'язання збігу: серед сутностей, чий шаблон повністю покриває знайдений текст, виграє та, у якої назва найдовша; якщо таких кілька різних — збіг пропускається (Лук / Лука → «Лука» = Лука).
- `findAutoMentionAtEnd(index, textBefore): { from: number; option } | null` — для живого режиму: збіг, що закінчується рівно в кінці переданого тексту.
- `autoTagDoc(doc, index): { doc; count }` і `autoTagContent(content, index): { content; count }` — для кнопки; тегає **всі** входження.
- Ніколи не тегає: всередині наявного `mention`; текст з marks `code`/`link` (розриває текстовий прогін, як не-текстовий вузол).

## Індекс імен (сервер → клієнт)

- `GET /api/campaigns/[id]/scenario/mention-names` → `MentionOption[]` (тільки DM, `requireDM`). Тонкий `route.ts` + `mention-names-handler.ts`; `listScenarioMentionNames(campaignId)` у `lib/server/scenario/mentions.ts` (select `id, name`, без ліміту — кампанії мають сотні сутностей, кілька КБ).
- `lib/api/scenario.ts`: `getMentionNames(campaignId)`.
- `lib/hooks/scenario/useAutoMentionIndex(campaignId)` — `useQuery` з `scenarioKeys.mentionNames`, `staleTime` 10 хв, без refetch on focus; `select` будує `AutoMentionIndex`. Один запит на сесію редактора — egress мінімальний.

## Живий режим (TipTap)

- Нове розширення `AutoMention` у `components/scenario/editor/rich-text/auto-mention.ts`; `buildExtensions(searchMentions, getAutoIndex?)` — геттер, щоб асинхронний індекс не перебудовував розширення.
- ProseMirror-плагін: `handleTextInput` для пробілу та розділових знаків (`, . ; : ! ? ) » " ' …`) і `handleKeyDown` для Enter. Береться текст текстового блоку від початку до курсора (неінлайнові/чипи → `￼`), `findAutoMentionAtEnd`; якщо є збіг і в діапазоні немає `code`/`link` — окрема транзакція заміни діапазону на mention-вузол з `closeHistory`, потім звичайна вставка символу / Enter. Отже перший Ctrl+Z скасовує лише перетворення.
- Поки індекс не завантажено або в активному `@`-підказнику — нічого не робить.

## Кнопка «Тегнути збіги»

- `ScenarioEditor`, другий рядок тулбара (поруч з «Властивості»): `HudButton`, вимкнена, поки індекс не готовий.
- `draft.setContent(c => autoTagContent(c, index).content)`; тост «Додано N згадок» / «Збігів не знайдено». Активна клітинка отримує новий doc через наявний ефект `RichTextEditor`.
- i18n: ключі в `messages/{uk,en}/scenario.json`; запис у `lib/onboarding/whats-new.ts` + `whatsNew.<id>` в обох локалях.

## Тестування

- `lib/utils/scenario/__tests__/auto-mentions.test.ts`: закінчення (Зехір → Зехіра/Зехіру/Зехіром, не «Зехірович»), заміна кінцевої голосної, фраза з закінченнями, регістр першої літери / ВЕРХНІЙ регістр не тегається, мін. довжина, неоднозначність (юніт+NPC з однаковою назвою), Лук/Лука, наявний чип не перетегується, `code`/`link`, `@` перед назвою, marks зберігаються.
- `wrap-mentions.test.ts` — без змін, має лишатися зеленим.
- `components/scenario/editor/rich-text/__tests__/auto-mention.test.ts` (happy-dom, реальний `Editor`): набір «Зехір» + пробіл → чип; `undo` → звичайний текст; без індексу нічого; неоднозначна назва не тегається.
- Тест хендлера: 403 для не-DM, формат відповіді.
- Живий прогін (браузер, сценарій кампанії HOMM5): набір імені героя/юніта → чип, Ctrl+Z, кнопка на вже написаній сторінці, збереження.
