# Бойова карта — специфікація епіку

Дата: 2026-10-18. Гілка: `feat/battle-map` (ворктрі `.claude/worktrees/battle-map`).

## Мета
Сцена бою стає картою: фон (картинка), сітка (квадрати або гекси, налаштовувана прозорість), токени учасників на клітинках. Учасники рухаються по клітинках, ближній бій вимагає сусідства, стрілок не стріляє з ворогом поруч, заклинання й постріли показують траєкторію і зону, а сервер сам визначає, кого зачепив шаблон.

## Рішення
- Форми сітки: `square` і `hex` (pointy-top, odd-r offset). Сітки «колом» немає.
- Розмір істоти: `gridSize` 1 / 2 / 3. Квадрат: `n×n` клітинок від якоря (лівий верхній). Гекс: 1 → одна клітинка, ≥ 2 → якір + 6 сусідів.
- Відстань: квадрат — Чебишев (діагональ = 1 крок, як у 5e за замовчуванням); гекс — кубічна відстань. Відстань між істотами — мінімум по парах клітинок.
- Рух: 1 крок = 1 клітинка, бюджет за хід = `floor(combatStats.speed / 5)` (speed уже містить запечені пасивки). Союзники прохідні, вороги — ні; закінчити хід на зайнятій клітинці не можна. Мертві й резерв клітинок не займають. Стан `immobilized` обнуляє рух.
- Вихід із сусідства з ворогом нічого не спричиняє (контратаки HOMM лишаються як є).
- Ближня атака: кожна обрана ціль на відстані ≤ 1. Дальня атака: заборонена, якщо поруч (≤ 1) живий ворог; ціль у межах дальності (`range` атаки, останнє число у футах / 5; без числа — без обмеження).
- AoE заклинань — шаблон на карті (коло/конус/лінія/куб), сервер рахує цілі (блок 3).
- Відео-фон — пізніше; v1 лише картинки.
- Старі бої без карти (`map = null`) працюють як раніше: жодних просторових правил. Учасник без позиції теж не підпадає під правила.

## Дані
- `battle_scenes.map JSONB NULL` — `BattleMapConfig { grid, cols, rows, background, opacity }`; задає ДМ у налаштуваннях бою (create/PATCH).
- Позиція й витрачений рух — у `battle_participants.state` (`position`, `movementUsed`), патчуються дельтою як `battleData.position` / `battleData.movementUsed`; відкат підхоплює їх зі `state`.
- `units.gridSize INT NOT NULL DEFAULT 1` → `combatStats.gridSize` у знімку. Герої — 1.

## Блоки (окремі плани й мерджі)
1. **Рушій**: геометрія, модель, авторозстановка, мутація `move`, правила атак. Без UI.
2. **UI карти + редактор**: рендер сітки й токенів, рух кліком/drag, вибір цілей на карті, вкладка «Карта» в налаштуваннях бою, бакет для фонів, desktop + mobile.
3. **Заклинання й AoE**: дальність і шаблони в `targeting`, серверний підрахунок цілей, аури за радіусом, заповнення бібліотеки (заклинання, `gridSize` юнітів).
4. **Візуалізація й перевірка**: траєкторії, превʼю шаблону, FX на токенах, battle-sweep із картою, браузерна перевірка.
