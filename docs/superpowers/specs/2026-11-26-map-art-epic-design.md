# Карти бою рівня еталонів — епік

Мета: DM за кілька хвилин отримує яскраву детальну карту бою (підлоги, стіни, меблі, світло, тіні) на квадратній або гекс-сітці. Механіка (стіни, двері, непрохідне) точно збігається з картинкою. Еталони: Inkarnate (encounter/city), dndungeon (throne room), The Caverns (модульні печери), добірка AI-карт власника.

## Рішення власника (2026-11-26)

- Якість досягаємо двома шарами: **штампи** (власний рендер сцени) + **AI-полірування** запеченої картинки.
- Основний сценарій — **автогенерація + доредагування**: тип локації, розмір, стиль → «Згенерувати» → правки інструментами → за бажанням AI-полірування.
- Ассети (текстури, штампи) **генеруємо AI за нашими промптами** в єдиному стилі, як іконки; DM-завантаження ассетів — не в першій хвилі.
- Типи локацій першої версії: **підземелля/печери, будівлі (таверна, храм, замок), природа (ліс, галявина, дорога), поселення/вулиці**.
- Гекси: **повна підтримка** — стіни, двері, ґрати, арт на гексах.
- Модель арту: **сцена шарів + запікання** у фон. Механіку виводимо зі сцени.
- Порядок: спершу фундамент.

## Частини

| Ч | Що | Результат |
|---|---|---|
| 1a | Ребра для обох сіток | Ключі ребер для квадрата й гекса; стіни/ґрати/двері на гексах у шляхах, видимості, тумані, шаблонах, поштовху; редактор ребер на гексах; двері з орієнтованим спрайтом |
| 1b | Сцена арту + запікання | Модель сцени, painter (підлоги без швів, стіни-ланцюги з поворотом/кутами/тінями, світло), запікання у фон, інструменти редактора; замінює клітинкові тайли |
| 2 | Штампи + пайплайн ассетів | Вільні штампи (позиція/поворот/масштаб/тінь); реєстр ассетів; пакети промптів для 4 біомів + скрипти (прозорість, безшовність, контакт-шити) |
| 3 | Генератор | Підземелля (кімнати+коридори), печери (cellular automata), будівля (кімнати за призначенням), природа, поселення → сцена; меблювання за правилами кімнати; seed; гекс і квадрат |
| 4 | AI-полірування | img2img по запеченому фону (OpenAI edits / Gemini з вхідним зображенням, BYOK); пресети стилю й сили; оригінал зберігається; механіка не змінюється |

Кожна частина проходить окремо spec → plan → SDD у свіжій сесії. Ч1 описана в `2026-11-26-map-art-ch1-foundation-design.md`. Ч2–Ч4 отримують власні spec'и перед стартом.

## Поза межами епіку

- Динамічне освітлення в бою (світло запікається).
- Анімований день/ніч (як у Inkarnate) — лише як можливий пресет AI/тону в Ч4.
- Карти світу (окремий епік world map).
