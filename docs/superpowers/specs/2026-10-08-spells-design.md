# Заклинання: нова модель і ребаланс бібліотеки (підпроєкт B)

- **Дата:** 2026-10-08 · **Гілка:** `feat/skills-rebalance` · **Батьківський spec:** `2026-10-07-skills-rebalance-design.md`
- **Вхід:** `imports/spells-import.csv` (48 заклинань, вільний текст ефектів). Заклинань у прод-кампанії ще немає — сумісність
  зі старою моделлю не потрібна.

## 1. Модель заклинання (з чистого листа)

| Поле | Значення |
|---|---|
| `school` | Світло / Темрява / Хаос / Природа (`SpellGroup`) |
| `level` | 1–5; вартість — слот цього рівня |
| `cost` | `action` (за замовчуванням) або `bonusAction` |
| `targeting` | `self` · `ally` · `enemy` · `allyDead` · `area { side, maxTargets }` · `allAllies` · `allEnemies` · `everyone` |
| `dice` | базові кубики `N` (див. «Сила») |
| `resolution` | `auto` або `save { ability, onSuccess: half \| none }` (DC = 8 + бонус майстерності + мод. заклинателя) |
| `effects` | `Effect[]` моделі абілок; цілі ефекту — цілі заклинання (`eventTarget`) або заклинатель (`self`) |
| `description`, `icon`, `appearanceDescription` | як зараз |

- **Сила — кубики (гравець кидає сам):** у заклинання базові кубики `dice: N`; фактично кидається
  `(N + ⌊рівень героя / 3⌋) к{грані}` без плоских бонусів (рівень героя і мод. характеристики до суми не додаються; мод. лишається лише в DC рятівного кидка). Грані — від прокачки гілки школи:
  без гілки / Базовий — к6, Просунутий — к8, Експерт — к10. Юніти: рівень юніта замість рівня героя, к6. Те саме — для
  лікування і DoT (DoT кидається один раз при накладанні). Бонуси шкоди школи з гілок (`damageBonus magic school`) — зверху.
- **Сила в таблицях §2 → базові кубики `N`:** 40–60 % → 1 · 80–100 % → 2 · 120–150 % → 3 · 180–200 % → 4 · 250 % → 5 ·
  300 % → 6 · 400 % → 8 (одинична ціль; «до N цілей» / «усі» — те саме число на кожну ціль). Відсотки баффів/дебаффів
  (−25 % шкоди тощо) — не кубики, лишаються відсотками. Остаточні `N` калібрує симуляція проти юнітів Tier 1–7 (20–200 HP).
- **Описи:** кожне заклинання (і кожен скіл бібліотеки) має два тексти — `description` «Що робить» (точна механіка живою
  мовою, числа з даних) і `appearanceDescription` «Як це виглядає» (атмосферний фентезійний абзац 2–4 речення).
- **Прибираємо:** кубики, `damageModifier/healModifier`, `effects[]`-теги, `effectDetails`, `damageDistribution`, `concentration`,
  `castingTime/range/components`, `hitCheck`; у скілів — `spellEnhancementTypes/…Data/TargetChange/EffectIncrease/AdditionalModifier`
  (заміна — `spellTargeting`, `damageBonus`, `spellCast`-тригери). Колонки спершу перестають читатися, видалення — пізніша міграція.
- **Юніти** теж кастують (`knownSpells`) за тією ж моделлю; сила — від їхньої атаки; слоти — «universal» як зараз.
- **Призвані юніти** керуються гравцем заклинателя.

## 3. Розширення двигуна (B)

1. **Нова модель заклинання** (§1): схема, форма DM (редактор ефектів — `AbilityListEditor`-поля), каст у бою через
   `runAbilities`-шлях ефектів, рятівний кидок, `spellTargeting` зі скілів, бонуси школи, книга заклинань у візарді.
2. **Ефект `hot`** — лікування на початку ходу цілі (дзеркало `dot`).
3. **Опір за видом атаки** — `resistance { attackKind: melee | ranged }`.
4. **Стан «пропуск дії з шансом»** на початку ходу.
5. **Стан, що знімається при отриманні шкоди.**
6. **Розподіл шкоди по цілях** (`falloff` для ланцюгових).
7. **Ціль `everyone`** (Армагеддон).
8. **Расові модифікатори шкоди** у заклинанні: `raceModifiers: { race, percent }[]`, −100 % = імунітет, +100 % = ×2.
9. **Шал**: стан, у якому хід цілі сервер виконує автоматично — атака по випадковій іншій істоті з бонусом шкоди.
10. **Тимчасова зміна сторони** (Ляльковод): сторона й `controlledBy` змінюються на N р., потім повертаються.
11. **`summon { unitId }`** — призив конкретного юніта бестіарію, обраного DM у заклинанні (поряд із `group/tier`).

## 4. Рішення (ухвалено 2026-10-08)

Телепортація — без механіки; Шал лишається (випадкова ціль, автоматичний хід); Ляльковод — тимчасовий перехід на бік
заклинателя; Армагеддон б'є всіх; Слово світла — імунітет добрих рас через расові модифікатори; призиви — юніт обирає DM;
концентрацію прибрано; сила = % атаки заклинателя.
