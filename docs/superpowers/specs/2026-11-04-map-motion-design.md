# Map motion («Рух»)

Візуальний режим карти бою: завантажена картинка безперервно їде під нерухомою сіткою, створюючи ефект, ніби герої біжать. ДМ під час бою міняє вісь, напрям і швидкість або зупиняє рух; гравці бачать зміни одразу.

## Узгоджене розуміння

- Рухається лише фон; сітка, місцевість, токени, ефекти не рухаються (варіант A з демо). Ходи, дальність і правила не змінюються.
- Картинка — звичайна завантажена ДМ (наявний `map.background`); окремих текстур, шарів і паралаксу немає.
- Зациклювання дзеркальне (картинка → її віддзеркалення вздовж осі руху), бо картинка не безшовна.
- Керує ДМ у бою: вертикально/горизонтально, напрям, швидкість, зупинка.

## Рішення

`map.motion` — окреме поле конфігу карти за зразком `map.weather`, **не** запис у `MAP_MODE_REGISTRY` (реєстр — для режимів, що змінюють правила: бачення, стіни, розстановка). Це робить рух сумісним із лабіринтом і не потребує хуків рушія.

### Дані

```ts
interface MapMotion { axis: "x" | "y"; speed: number }  // BattleMapConfig.motion?: MapMotion | null
```

- `speed` — клітинки за секунду зі знаком (знак = напрям вздовж осі), `|speed| ≤ MAP_MOTION_MAX_SPEED` (6). `0` — зупинено; відсутнє/`null` — вимкнено.
- Фаза не синхронізується: кожен клієнт крутить власну, по мережі йдуть лише `axis` і `speed` (нуль трафіку між змінами, без залежності від годинників; Supabase egress).
- `BattleMapConfig` і `sanitize` карти приймають поле; скидання бою його зберігає.

### Відображення (`components/battle/map/motion/`)

- У `MapBackground`: якщо `map.motion` задано — рендер `MotionBackground` замість статичного `<Image>`. Картинка вписується так, щоб покривати всю карту (cols×rows) по осі, перпендикулярній руху; `backgroundCols` і `gridOffset` у режимі руху ігноруються (зафіксувати в підказці в налаштуваннях).
- Тайл = картинка + віддзеркалена копія вздовж осі руху; розмір періоду = 2 × розмір картинки вздовж осі. Фон — CSS `background-image` з повтором вздовж осі, позиція рухається через `transform: translate3d` у `requestAnimationFrame`.
- Швидкість у px/с = `speed × cellPx`, тож масштабується разом із зумом/екраном.
- Плавний розгін/гальмування: поточна швидкість наближається до цільової експоненційно (~0.3 с).
- Анімація на паузі, коли вкладка прихована; при `prefers-reduced-motion` картинка стоїть, а ДМ у панелі бачить підказку.
- Карта в мобільному повороті: вісь рахується в тому вигляді, який бачить гравець (поворот не змінює напрям).

### Керування ДМ

- Панель «Рух» поруч з `MapWeatherPicker`: перемикач осі, розворот напряму, повзунок швидкості з пресетами (повільно ≈1, середньо ≈2.5, швидко ≈5) і кнопка «Зупинити/Продовжити». Вимкнути режим повністю — окрема дія «Вимкнути».
- Продовжити після зупинки повертає останню ненульову швидкість (зберігається лише на клієнті ДМ).
- Сервер: `POST /api/campaigns/[id]/battles/[battleId]/map-motion` → `runBattleMutation({ operation: "map-motion" })`; `lib/server/battles/mutations/map-motion/map-motion-mutation.ts` пише `scene.map` (мутація — копія шаблону `map-weather`), відповідь — дельта.
- Zod-схема `mapMotionSchema` у `lib/schemas/battles.ts` (`motion: { axis, speed } | null`, `speed` обмежена); `MapMotionData` у `types/api.ts`; клієнтська обгортка `lib/api/battles` (поруч з weather); хук `useMapMotionTool` (за зразком `useMapWeatherTool`) у `lib/hooks/battle/`.
- Помилки: `BATTLE_NO_MAP` для бою без карти — як у weather.

### Повторне використання

| Що | Звідки |
| --- | --- |
| Шаблон мутації та роуту | `map-weather` (`mutations/map-weather`, `app/api/.../map-weather`) |
| Шаблон хука й панелі | `useMapWeatherTool`, `MapWeatherPicker` |
| Конвеєр дельт | `runBattleMutation`, `ClientBattleDelta` |
| Розмір/позиція фону | `backgroundBox` (`lib/utils/battle/grid`) |
| Приховування анімації у фоні | наявні хуки видимості/`prefers-reduced-motion`, якщо є в `lib/hooks/common` (перевірити перед написанням) |

Нове потрібне, бо: `MapBackground` статичний, дзеркальний тайл і rAF-анімація в ньому відсутні.

### Свідомо не робимо

Паралакс і окремі текстури/шари; власне завантаження картинки для руху; синхронізацію фази між клієнтами; запис режиму в `MAP_MODE_REGISTRY`; вплив руху на ходи, дальність чи ефекти.

## Тести

- Чисті функції в `lib/utils/battle/map-motion/`: нормалізація й обмеження швидкості, період тайла, крок позиції `step(phase, speed, dt, period)`, згладжування швидкості.
- Схема й мутація (`map-motion-mutation`: вмикання, зміна, `null` прибирає поле, відсутня карта → помилка).
- Компонент панелі: пресети, зупинка/продовження, вимкнення; хук викликає мутацію лише при зміні.
- `MotionBackground`: з `motion` рендерить тайл, без — статичний фон; reduced-motion не запускає анімацію.
