# Ребаланс юнітів (бестіарій HOMM5) — дизайн

Дата: 2026-10-08. Гілка: `feat/units-rebalance`. Джерело: Notion «Бестіарій» (`2e64f3c4839680f3a671e49310630856`), дамп —
`2026-10-08-units-notion-source.json` поруч. Попередні проходи: скіли (`2026-10-07-skills-rebalance-design.md`), артефакти
(`2026-10-08-artifact-sets-and-crits-design.md`).

## 1. Мета і рамки

Зараз бестіарій живе лише в Notion (6 баз, 109 заповнених рядків) і в `imports/units-import.csv`. CSV містить тільки Демонів, і розібраний він погано: `damageDice: "12"`, ініціатива 10 у всіх, Суккуб має «Ріг» і «Копита». Здібності юнітів імпортуються як `note` і не працюють. У прод-кампанії HOMM5 немає жодного юніта, тож не працюють призив Демонів, «Поклик звіра», «Аватар» і підбір складу для чесних боїв.

Мета — `data/library/units.ts` як єдине джерело правди, як для скілів і артефактів. Юніти будуються за HOMM5 і вдалими ідеями з Notion, збалансовані за тірами, з механіками, що працюють через рушій здібностей, і сідяться через `seed-library`.

Рішення користувача:
- Люди й Темні ельфи (у Notion їх немає) створюються з HOMM5 повністю, по 21 юніту.
- Джерело — склад і здібності HOMM5 плюс ідеї з Notion; копіпасти замінено.
- Таблиці погоджено раса за расою; вони наведені в §4.
- На юнітів діє **лише расова пасивка**; вміння з расового дерева — тільки для героїв.
- «Мультиатака» — це атака по кількох цілях (`maxTargets` + `damageDistribution`), а не кілька ударів за хід.
- Елементалі масштабуються від рівня заклинателя й прикликаються 4 новими закляттями Природи.

Поза рамками: іконки юнітів (окремий прохід, як D у скілах), ШІ для юнітів, сітка/рух.

Критерії успіху:
- 152 юніти (7 × 21 + 5 нейтралів) у бібліотеці, валідні.
- Кожна здібність має механіку; `note` — лише антураж.
- `balance-library`: множники чесного балансу 0.8–1.25 і 70–90 % перемог героїв для L3↔T1, L6↔T4 і L10↔T7.
- Прод-кампанія HOMM5 засіяна.

## 2. Загальні правила

### 2.1 Склад
7 тірів × 3 юніти: базовий, покращення, альтернативне покращення (Tribes of the East).

|---|---|---|---|---|

| T2 | 41 | 6 | 13 | +5 |
| T3 | 55 | 8.8 | 13 | +6 |
| T4 | 76 | 12.6 | 14 | +7 |

Таблицю підігнано за `balance-library` (звіт `docs/reports/2026-10-08-units-balance.md`); початкова була 12/22/36/58/90/140/220 HP, 4.5/7/10/14/20/28/40 шкоди, КД 11…18, атака +3…+10. «Шкода/хід» — середнє кубиків атаки; рушій додає ще модифікатор характеристики (атака − майстерність). «Атака» — повний бонус влучання.

- **Покращення** — ≈ +25 % сили: HP і шкода +10–12 % і ще одна здібність.
- **Альтернатива** — та сама сила, що й у покращення, але інша роль.
- **Стрільці, заклиначі й юніти з сильним контролем** — ≈ −15 % бюджету.
- **Здібності:** якщо здібність сама дуже сильна («Без відповіді», атака по кількох цілях), бюджет числами трохи нижчий.
- Відхилення ±20 % від бюджету допустиме і перевіряється тестом (§6).

### 2.3 Характеристики
- СИЛ…ХАР виводяться з бюджету: основний модифікатор = атака − бонус майстерності.
- Ініціатива — з HOMM5 (7…19).
- Мораль за замовчуванням +1; Нежить, Механізми й Елементалі ігнорують мораль.
- Атака має тип шкоди; додаткова стихійна шкода задається окремою групою кубиків.

### 2.4 Механіки
- 1–3 здібності на юніта, лише через наявні тригери й ефекти рушія. Чого бракує — точкові правки з тестом (§5).
- `note` — тільки для антуражу (політ 🪽, розмір, телепорт).
- Шанси кидає сервер.

### 2.5 Расові пасивки (діють на юнітів)
- Люди — «Вишкіл війська»: +1 моралі союзникам на 2 раунди. **Один раз на сторону**, а не від кожного юніта.
- Демони — опір вогню 50 %.
- Ельфи — +1 атаки.
- Некроманти — мораль 0, імунітет до отрути.
- Маги — опір закляттям 15 %.
- Темні ельфи — перша атака з перевагою.
- Гноми — +1 КД.

## 3. Каталог здібностей юнітів

`data/library/unit-abilities.ts` — фабрики з параметрами (шанс, відсоток, цілі), на які посилаються юніти.

| Здібність | Механіка | Рушій |
|---|---|---|
| Без відповіді | на атаку юніта ціль не відповідає | 🆕 прапор `noRetaliation` |
| Безмежна відсіч | відповідає на кожну атаку | 🆕 прапор `unlimitedRetaliation` |
| Подвійний удар/постріл N % | з шансом N % — ще одна атака, раз за хід | `grantAction` на `attack after`, `chance` |
| Атака по кількох цілях (Подих, Розмах, Залп, Вихор, Триголова, Колючки…) | 2–3 цілі 100/50(/50) % | `maxTargets` + `damageDistribution` |
| Таран / Засідка / Пікірування | перша атака в бою +50 % | `damageBonus`, `perBattle: 1` |
| Смертельний удар / Точний постріл | N % шанс ×2 шкоди | `damageBonus` 100 % з `chance` |
| Броньобійність / Магнітний удар / Гарпун | влучання: −2 КД цілі на 1 раунд | `modifyStat armor` на ціль |
| Лють | +25 % шкоди на 2 раунди, коли гине союзник | тригер `kill` (victimSide) |
| Ненависть / Свята кара | +25 % шкоди проти раси | 🆕 умова `targetRace` |
| Оглушення / Паралізація / Сплутування / Збивання | N % шанс: ціль пропускає хід | `applyCondition skip_action` |
| Отрута / Опік / Кровотеча | DoT кубиками на 2–3 раунди | `dot` |
| Каліцтво / Підрізання / Удар лапою / Прокляття | −атака або −ініціатива цілі | `modifyStat` на ціль з тривалістю |
| Аура страху / Аура величі | вороги −1 моралі | пасивка `modifyStat morale` allEnemies |
| Саботаж | ціль 1 раунд без дальніх атак | `applyCondition disable_ranged_attacks` |
| Нежить / Механізм / Елементаль | ігнор моралі, імунітет до страху (+ стихії) | `ignoreMorale`, `conditionImmunity`, `resistance` |
| Опір магії N % / Повний імунітет до магії | менше шкоди від заклять / імунітет | `resistance spell` / `spellImmunity` |
| Вразливість ×2 | стихія б'є подвійно | 🆕 від'ємний `resistance` |
| Безтілесний | атакувальники з недоліком | `disadvantageForAttackers` |
| Регенерація N % | лікування на початку ходу | `heal` на `turnStart` |
| Висмоктування життя | лікує 50 % завданої шкоди | `lifesteal` |
| Вогняний щит / Кислотна кров / Аура стихій / Вогонь помсти | атакувальник у ближньому бою отримує 25 % шкоди | `dealDamage percentOf eventDamage` на `hit` (target) |
| Захисник | бере 30 % шкоди союзника | `guard` |
| Великий щит | −30 % дальньої шкоди | `resistance` з `attackKind: ranged` |
| Сміливість | імунітет до страху, мораль ≥ 0 | `conditionImmunity` + `minMorale` |
| Нежива стійкість | раз за бій смертельний удар лишає 1 HP | `lethalDamage` |
| Заклинач | 1–3 закляття бібліотеки | `knownSpells` |
| Лікування / Симбіоз / Ремонт / Покладання рук | дія або бонусна дія: `heal` (+`cleanse`) | `heal` |
| Воскресіння | раз за бій: союзник повертається з 50 % HP | `raiseDead` |
| Благословення / Божественна сила / Батіг | союзник +2 атаки (або +1 моралі й +2 ініціативи) на 2 раунди | `modifyStat` на союзника |
| Енергетичний канал / Передача мани | раз за бій: союзник відновлює слот | `restoreSpellSlot` |
| Крадіжка мани | влучання: ціль втрачає 1 слот | 🆕 ефект `drainSpellSlot` |
| Виклик пекла | раз за бій: прикликає Демона T6 | `summon {group, tier}` |
| Підняття мертвих | вбивство: прикликає Скелета, раз за раунд | 🆕 `summon` на `kill` |
| Колесо фортуни | раз за раунд: випадковий баф союзнику або дебаф ворогу | `randomOf` |

## 5. Рушій (точкові правки, кожна з тестом)

1. **Прапори `noRetaliation` і `unlimitedRetaliation`** — у `lib/utils/battle/attack/retaliation.ts` і в схемі прапорів (`lib/utils/abilities/schema/effects.ts`).
2. **Умова `targetRace`** (назва раси) — схема `conditions.ts` + її обчислення.
3. **Ефект `drainSpellSlot`** — ціль втрачає N слотів, найвищі першими.
4. **`resistance.percent` від −100 до 100** — від'ємний відсоток означає вразливість.
5. **`summon` на тригері `kill`** — з лімітом раз за раунд.
6. **`levelScaling { hpPerLevel, damagePerLevel, attackPerTwoLevels }`** — на юніті. Застосовується при прикликанні здібністю чи закляттям за рівнем заклинателя; ігнорується, коли юніта додає DM.
7. **Перевірити без змін:**
   - ауровий `modifyStat`/`resistance` на allAllies/allEnemies;
   - `damageBonus` з `chance`;
   - `heal` на `turnStart`;
   - `randomOf`;
   - `lethalDamage`.

   «Вишкіл війська» має спрацьовувати один раз на сторону.

## 6. Бібліотека та сід

**Нові файли в `data/library/`:**
- `unit-abilities.ts` — каталог фабрик здібностей (§3).
- `units.ts` — `LibraryUnit` з такими полями:
  - `name`, `race | null`, `tier`, `hp`, `ac`, `attackBonus`, `initiative`, `morale?`;
  - `attacks[]` — тип, шкода, тип шкоди, `maxTargets`, `damageDistribution`, додаткова шкода;
  - `abilities[]`, `spells?` (назви), `levelScaling?`.

  СИЛ…ХАР обчислює хелпер.

**Перевірка в `types.ts` / `build.ts`** (Zod):
- унікальні назви;
- раси й закляття існують;
- тір 1–7, по 21 юніту на расу.

Окремий тест бюджету: HP і шкода в межах ±20 % від бюджету тіру з урахуванням ролі.

**Сід — `scripts/seed-library-lib.ts`:**
- upsert юнітів за назвою (без урахування регістру);
- назви заклять перетворюються на id;
- закляття з `summon` за назвою юніта резолвляться після юнітів.

**Старе джерело виводиться з ужитку:** `imports/units-import.csv` та `import-units`. `balance-library` і `simulate-battle-scenario` беруть юнітів із бібліотеки.

## 7. Перевірка

- `pnpm test:run`, `pnpm lint`, `pnpm exec tsc --noEmit`, `pnpm simulate-battle`.
- `pnpm balance-library --runs=12` на локальній БД:
  - пари L3↔T1, L6↔T4 і L10↔T7 для складів кожної раси;
  - ціль: множники 0.8–1.25 і 70–90 % перемог героїв;

  Звіт іде в `docs/reports/2026-10-XX-units-balance.md`.
