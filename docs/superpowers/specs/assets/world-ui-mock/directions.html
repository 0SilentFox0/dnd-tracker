Карта світу — три напрямки

Статичний мокап до брифу 2026-10-28-world-map-ui-polish.md. Фон — умовний «намальований» рельєф; на реальній карті Ашану контраст вищий. Кольори й шрифти — з components/hud/hud.css і app/globals.css (Alegreya SC = hud-sc).

Піни, зони, підписи

A · HUD-тактична карта

Irollan Ranaar ♜ ⌂ Al Safir ♜ Talonguard
  • Пін — металевий жетон 28–32 px з іконкою (як токен бою + .map-hud-plaque).
  • Підпис піна — плашка під жетоном, лише hover / selected / zoom ≥ 1.6.
  • Зона: обране — подвійна обводка (світле золото + колір зони), hover — fill-opacity .28 → .4.
  • Ризик: на яскравій карті «ігровий» HUD сперечається з малюнком.

B · Атлас / пергамент

IROLLAN RANAAR ♜ ⌂ Al Safir ♜ Talonguard
  • Пін — «сургучна печатка»; підпис — курсив чорнилом з ореолом, без плашки.
  • Зони — пунктир «кордону» чорнилом, назва розрядкою, як на старих мапах.
  • Сильно пасує до HOMM-карти, але чужий для решти HUD (бій, Показ) і погано читається на темних/синіх ділянках.

C · Гібрид (рекомендовано)

IROLLAN RANAAR ♜ ⌂ Al Safir ♜ Talonguard
  • Що «належить карті» (зони, їхні назви) — картографічно: розрядка hud-sc, текст з обводкою, без плашки.
  • Що «належить застосунку» (піни, вибір, інструменти) — HUD: жетони, золото, metal-gold.
  • Обране — золотий контур + темна підкладка під ним (читається на будь-якому кольорі).
