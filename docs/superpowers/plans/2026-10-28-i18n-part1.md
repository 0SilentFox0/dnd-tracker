# i18n part 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** помилки API приходять мовою запиту (`errorResponse` перекладає ключі `errors.*` на сервері), спільний UI (`components/{common,ui,layout,hud}`, `lib/hooks/common`, error/not-found/loading, `settings/password`) — на `next-intl`, серверний Zod віддає ключі `validation.*`, закрито шість хвостів частини 0.

**Architecture:** значення `API_ERRORS` стають ключами; `apiErrorJson` повертає `NextResponse` одразу, а тіло — лінивий `ReadableStream`, що в `start` читає мову запиту й викликає чисту `translateErrorBody`. Стоки повз `errorResponse` переходять на `apiErrorJson`/`translateErrorBody` **до** перемикання значень на ключі. Namespace `errors` лише серверний.

**Tech Stack:** next-intl 4 / use-intl `createTranslator`, Next 16 route handlers, Zod 4 `z.config({ customError })`, Vitest 4, ESLint 9.

**Spec:** `docs/superpowers/specs/2026-10-28-i18n-part1-design.md` (розділи «Рішення 1–7» — джерело правди; тут лише сигнатури, порядок, тест-кейси й неочевидний код).

```ts
export function apiErrorJson({ error, issues, params, ...rest }: ApiErrorInput, init: ResponseInit = {}): NextResponse {
  const headers = new Headers(init.headers);

  headers.set("Content-Type", "application/json");

  const stream = new ReadableStream<Uint8Array>({
    // start runs synchronously inside the constructor, so the request's async context (cookies/headers) is still active
    async start(controller) {
      const body = await translateInRequest({ error, issues, params });

      controller.enqueue(new TextEncoder().encode(JSON.stringify({ ...rest, ...body })));
      controller.close();
    },
  });

  return new NextResponse(stream, { ...init, headers });
}

async function translateInRequest(body: { error: string; issues?: unknown; params?: ErrorParams }): Promise<ApiErrorBody> {
  try {
    const locale = await getRequestLocale().catch(() => DEFAULT_LOCALE);

    return translateErrorBody(await getTranslator(locale), body);
  } catch {
    return { error: body.error, ...(body.issues !== undefined && { issues: body.issues }) };
  }
}
```

```ts

Виклики: `GET /api/locale` (cookie з `req.cookies`), `app/auth/callback` (замість прямого читання `user.locale`). Повернене не-`null` → `setLocaleCookie(res, locale, req)` як зараз.
