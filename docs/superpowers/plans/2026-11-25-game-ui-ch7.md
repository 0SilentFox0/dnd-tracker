## Ч7a

### A1. Поле gridType + hex геометрія (1 виконавець)
Файли: `types/battle-grid.ts`, `lib/schemas/battles.ts`, `lib/utils/battle/grid/{hex.ts,geometry.ts,layout.ts,index.ts}`, тести в `__tests__/`.
- `GridKind = 'square'|'hex'`; `gridType?: GridKind` у конфіг і `battleMapObject` (`z.enum().optional()`).
- `gridOf(map: Pick<BattleMapConfig,'gridType'>): GridKind`.
- `hex.ts` (odd-q): `toCube/fromCube`, `hexNeighbors(p)`, `hexDistance(a,b)`, `hexLine(a,b)`, `hexCenter(p)`, `hexPolygon(p)`, `hexPointToCell(x,y)`, `hexMapSize(cols,rows)`; одиниці в просторі `UNIT=100` (width 2·R, height √3·R, flat-top).
- `geometry.ts`: останній параметр `grid: GridKind = 'square'` у `neighbors`, `cellDistance`, `footprintDistance`, `cellLine`, `cellsByRing`, `cellsByDistance`; footprint hex size>1 = 1 клітинка.
- `layout.ts`: `cellCenter/cellPolygon/tokenBox/fitMapBox/cellAtScreenPoint` з параметром `grid`.
- Тести: round-trip center↔cell для 0..10×0..10, 6 сусідів парної/непарної колонки, `hexDistance` проти cube-еталона (випадкові пари), `gridOf(undefined)==='square'`, схема приймає/зберігає поле і старий payload без нього ідентичний, усі наявні square-тести без змін.
- Критерій: `tsc` по папці, square тести зелені.

### A2. Створення + потік карти (1 виконавець, батч з A1 можливий)
Файли: `components/maps/CreateMapDialog.tsx`, `lib/hooks/battle-maps/useMapEditorDraft.ts`, форма налаштування бою (`BattleSetupForm`/`useBattleMapEditor`), `lib/server/content/copy/maps.ts`, `messages/{uk,en}/*.json`, тести.
- Segmented вибір «Квадрати / Гекси» (reuse hud-контроль), дефолт square, ключі i18n uk+en; hex вимикає режим maze і шари тайлів/стіни в редакторі (прихований/disabled з підказкою).
- Перевірити, що clone, content copy, `client-delta`, `merge-header` не відкидають поле (тести: створити hex → клон → поле лишилось).

### A3. Бойові виклики + рендер сітки (2 виконавці послідовно)
A3a (логіка): `path.ts`, `adjacency`, `adjacent-attack`, `nearest`, `push`, `placement`, `revive-placement`, `attack-reach`, `reach-check`, `template`, `line-of-fire` і решта викликів `footprintDistance/cellDistance/neighbors/cellLine` з `grep`: передати `gridOf(map)` де карта в області; у hex прибрати вартість діагоналі. Тест-ratchet `lib/__tests__/grid-calls.test.ts`: у перелічених файлах виклики без grid заборонені. Тести hex-руху і досяжності (6 сусідів, бюджет, вартість).
A3b (рендер): `grid/{GridLayer,GridStatic,GridMarks,GridHit,region-path}`, `tokens/token-box.ts`, `useBattleMapFrame`, `MapStage`, камера/мінімап: grid-aware polygons; hex без merged row-run (поклітинні polygons, мемо). Тести GridHit/GridStatic/GridMarks hex+square.
Не чіпаємо: Walls/Doors/Tiles/maze/edge-chunks.

### A4. Новий вигляд дальності + шлях (1 виконавець)
Файли: `grid/GridMarks.tsx`, `grid/MapPathPreview.tsx` (новий), `lib/utils/battle/grid/map-scene.ts` (експорт `search`), `battle-map.css`, палітри токенів, тести.
- Токени `--reach-fill/--reach-stroke/--threat-tint/--threat-stroke` для темних і parchment/frost; заливка move = низька альфа, контур 1.5px; threat = dashed `stroke-dasharray`; fade 160 ms, `prefers-reduced-motion` без transition.
- `MapPathPreview`: `pathFrom(view.search, mover, hover)` + підпис вартості біля курсору; на touch після вибору клітинки; ховається поза чергою/вибором.
- Тести: клас/атрибути dashed, відсутність шляху для недосяжної клітинки, reduced-motion.
- Критерій: геометрія шляху = `pathTo` результат (тест порівнює).

## Ч7b

### B1. Спільне ядро туману (1 виконавець)
Файли: `lib/hooks/common/useFogQuality.ts` (+ barrel), `components/battle/map/fog/{FogSurface.tsx,fog-mask.ts,fog-cloud.ts}`, вихід спільного з `components/world/map/world-cloud-texture.ts`, CSS `--fog-*`.
- `fog-mask.ts` (pure): `cellsToMask(cols,rows,visible,explored)` → маленький `Uint8ClampedArray`/canvas-дані, ключ кешу за вмістом, `diffAdded(prev,next)`.
- `FogSurface`: вхід `{mask, cellPx, quality, revealedAdded}`; feather blur, `destination-out`, дрейф через `ticker` (30 fps, пауза hidden/off-screen), dpr ≤1.5, phone scale .5.
- `useFogQuality(): 'live'|'still'|'flat'`.
- Тести: `cellsToMask`, diff, `useFogQuality` матриця (reduced, phone, saveData, hidden), `FogSurface` режими.

### B2. Бій і лабіринт (1 виконавець)
`MapFogLayer` → `FogSurface` (props і монтування лишаються, DM-гілки без змін), `MazeFogOfWar` → canvas-сиблінг у transform-просторі, оновити `battle-map.css` (`.maze-fog`). Тести переписати на семантику маски; `data-maze-fow-layer` лишається.

### B3. Світ (1 виконавець, може разом з B2)
`WorldFog` на спільні модулі (ticker, `useFogQuality`, текстура). Поведінка/props незмінні; `WorldFog.test` зелений без правок логіки.
