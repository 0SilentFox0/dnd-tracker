# Ч2 — Campaign Dashboard Implementation Plan

> Статус: Ч2 епіку game-style UI; 2026-11-22: доведено наживо (Chrome-розширення, desktop/phone, tavern/parchment, production build). Рішення власника: без пошуку й без секції «Розділи»; блок квестів прибрано (моделі квестів немає, Ч3); швидкі дії — 2 в ряд.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Перебудувати огляд кампанії `/campaigns/[id]` за стилем і композицією затвердженого Ч0-прототипу, зберігши справжні дані, рольовий доступ і чинні дії.

**Architecture:** Зберегти серверну сторінку як джерело авторизації та даних. Перекомпонувати наявні рольові картки, навігаційні групи, зведення й список учасників у виразний адаптивний огляд; для відсутніх джерел даних не створювати демонстраційних значень.

**Tech Stack:** Next.js App Router, React Server Components, Tailwind CSS, `next-intl`, наявні HUD-компоненти.

**Spec:** `docs/superpowers/specs/2026-11-21-game-style-ui-approved-design.md` (розділ «Дашборд кампанії»), прототип `docs/superpowers/prototypes/2026-11-21-game-style-ui-ch0.html` (`#dashboard`).

## Global Constraints

- Зберегти чинні доменні дані, рольову видимість, авторизацію та маршрути кампанії.
- Використовувати наявну темну/світлу палітру й HUD-компоненти.
- Не показувати вигадані дати сесій, квести, підсумки, онлайн-статуси, статистику загону чи бібліотек. Якщо для секції немає окремої моделі, показати чесний порожній стан і наявний суміжний перехід.
- Зберегти доступність елементів і всі чинні переходи, пошук і онбординг.
- Не змінювати інші екрани, бойові дані чи правила.
- Запускати тільки цільові `pnpm test:related` та ESLint для зачеплених файлів; повний suite й repo-wide lint не запускати.

## Review Focus

- Ролі DM, гравця, демо та шаблону мають бачити свої чинні панелі й дії — перевірити умови рендерингу в `app/campaigns/[id]/page.tsx`.
- Кампанії без персонажа чи мапи мають зберігати сітку через підписані empty states, без вигаданих значень.
- Вузький екран не має обрізати картки, навігацію чи довгі назви — виконати ручний responsive-огляд.
- Перекомпонування не має прибрати пошук розділів, налаштування, список учасників чи чекліст — перевірити збереження кожного наявного входу.
- Квестів і наративного підсумку сесії в поточній моделі немає: блок квестів явно повідомляє про це й веде ДМ до сценарію; картка сесії використовує лише фактичні `WorldSession` і пов'язані локації.
