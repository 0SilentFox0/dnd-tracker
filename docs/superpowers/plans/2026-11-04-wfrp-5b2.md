# WFRP 5b-2: Momentum на сцені й хвости рушія — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Перенести Momentum wfrp з учасників на сцену (`battle_scenes.momentum`) зі спільним шляхом для гравецьких і серверних атак, і закрити хвости рушія 5b-1 (`InitiativeRollEntry`, `moveYd`, обов'язковий `rules`).

**Architecture:** `SceneMomentum = { ally?: true; enemy?: true }` живе в `BattleSceneState`, ходить тим самим шляхом, що `pendingCritChoice` (load → mutation ctx → `ScenePatch` → save → delta → client). Чиста утиліта `momentum.ts` (`heldBy`, `settle`) — єдина реалізація для `judgeWfrp` і `judgeServerWfrp`. `ActionFlow.momentum` несе стан у дії; п'ять точок, що судять атаку, беруть його зі сцени й повертають наступний.

**Tech Stack:** TypeScript strict, Prisma 6 (expand-only міграція), Vitest, TanStack-клієнтський кеш через `apply-delta`.

**Spec:** `docs/superpowers/specs/2026-11-04-wfrp-5b2-design.md` (читати разом з планом). Гілка `feat/wfrp`, worktree `/Users/silentfox/Work/dnd-tracker-wfrp`. **Нічого не мерджити й не пушити в main** до явного «епік готовий».
