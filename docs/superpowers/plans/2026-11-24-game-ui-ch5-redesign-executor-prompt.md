## Планка власника (діє для всіх екранів)
«Преміум» = стриманість, чітка ієрархія (акцент на найважливішому для гри), зручність і доступність: контраст ≥ 4.5:1 (UI-частини ≥ 3:1) у темній і світлих палітрах, цілі ≥ 40 px, не лише кольором (володіння ромбом/формою + sr-only), focus-кільця, `prefers-reduced-motion`. Золото лише для змісту (володіння, вибрана вкладка, головна дія), червоний лише HP. Без орнаментів, глоу, частинок, зайвих рамок (один рівень межі, одна тінь, групування відступами). Форми: заокруглений квадрат, без гексів. Ще потрібен «вау» через РУХ (див. нижче), а не через декор.

## Рух (обовʼязково, CSS/WAAPI, лише transform/opacity, 60 fps)
Токени тривалостей 120/200/320/480 мс, 2–3 easing (один пружинний), stagger ~35 мс; у `prefers-reduced-motion` лишається спокійна заміна (миттєво/короткий fade). Перед власним кодом перевір наявне: `components/layout/PageTransition`, `lib/hooks/common`, залежності в package.json (не додавай бібліотеку руху без потреби). Реалізуй: (1) перехід вкладок: індикатор ковзає й розтягується між вкладками, вміст виходить/входить із напрямком (вправо → нова панель зʼїжджає справа), короткий stagger блоків, плавна висота; стрілки на клавіатурі; свайп між вкладками на phone за можливості; (2) поява екрана: блоки збираються по черзі, числа (HP, КЗ, модифікатори, бонуси) плавно «набігають» один раз, смуги XP і HP заповнюються; (3) HP: при шкоді смуга зливається з хвостом-«привидом» і число коротко спалахує, лікування піднімає, тимчасові як накладний сегмент; відгук натискання (scale .97), hover-підйом карток; (4) кидок навички/характеристики: коротка анімація кубика, потім результат; нат-20/нат-1 лише стриманий акцент без конфеті; (5) LVL UP: спокійний пульс лише на головній кнопці. Хуки (`useCountUp`, `useReducedMotionSafe`, `TabPanelTransition` тощо) клади в `lib/hooks/common` або поряд зі споживачем за шарами UI; тести на логіку (число набігає до цілі, reduced-motion вимикає).
