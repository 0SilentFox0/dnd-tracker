# Пункт 10 — HUD-форми, таби замість акордеонів — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Усі форми створення й редагування мають стилістику сторінки прокачки (HUD), акордеони у формах стають табами (форми) і чипами-табами (редактор вмінь). Поведінка й дані не змінюються.

**Architecture:** Перевизначаємо shadcn-токени в `.hud-surface` (`components/hud/hud.css`), тож наявні листові поля темніють без правок. Нові примітиви у `components/hud/form/` (`HudTabs`, `HudSection`, `HudForm`, `HudFormPage`) і `PortalContainerProvider`, щоб портальні попапи (Select, Dropdown, Tooltip) лишались усередині HUD-поверхні. Кожна форма загортається в ці примітиви; її поля, хуки й обробники не змінюються.

**Tech Stack:** Next.js 16 App Router, React 19, Tailwind v4, Radix Tabs/Select (shadcn), vaul, Vitest + Testing Library (happy-dom).

**Spec:** `docs/superpowers/specs/2026-10-06-forms-hud-design.md`

## Global Constraints

- Поведінка й дані форм не змінюються: ті самі поля, хуки, запити, валідація, назви кнопок і доступні імена (тести на них спираються).
- 390 px: немає горизонтального скролу сторінки, ActionBar не обрізається, смуга табів скролиться сама в собі.
- Акордеони в списках (юніти, заклинання, скіли, артефакти, довідник, `UnitsListCard`) лишаються акордеонами.
- Жодних нових «магічних» рядків для доменних значень: константи в `lib/constants`. Ідентифікатори табів — `as const` об'єкт поруч із формою (`export const UNIT_FORM_TAB = { basic: "basic", ... } as const`).
- Палітра (точні значення): фон `radial-gradient(120% 80% at 50% 0, #1d1611, #0b0908)`, поле `#1a140f`, рамка `#4a3c2c`, тонка лінія `#3a2e22`, текст `#e6dccb` / `#efe5d2`, приглушений `#8f8473`, золото `#c9b37a`, метал `#8a6414 → #e6c25a 55% → #8a6414`, текст на металі `#2a1d05`, помилка `#d0705c`.
- Коментарі мінімальні (лише неочевидне «чому», один рядок). Видаляти зайві коментарі у файлах, які редагуєш (наприклад, шапку-JSDoc у `FormCard`).
- Імпорт `@/…`, порядок `simple-import-sort`, порожні рядки навколо `const`/`if`/`return` (`pnpm exec eslint --fix <files>`).
- Діалоги — лише `ResponsiveDialog`. Компоненти не імпортують `@/lib/api/*`.
- Режим економії: після кожного блоку `pnpm test:run && pnpm exec tsc --noEmit` + `pnpm exec eslint <змінені файли>`; повний `pnpm lint` раз на блок.

### Рецепт переробки форми (використовують задачі 8–18)

1. Сторінка: замість `container mx-auto p-4 max-w-*` + `Card/CardHeader/CardContent` → `<HudFormPage title="…" aside={…}>`.
2. Форма: `<form>` + `ActionBar` → `<HudForm id="<entity>-form" onSubmit={…} tabs={[…]} actions={<>…кнопки…</>} />`. Кнопки — ті самі елементи `Button` з тими самими текстами, `disabled` і обробниками. Головна дія — `type="submit"` (`variant` за замовчуванням). Скасувати — `variant="outline"`. Видалити — `variant="destructive"`.
3. Псевдозаголовки (`Label className="text-base font-semibold"`, `h3/h4 font-semibold`, `border-t pt-4`, рамки `rounded-md border p-4`) → `<HudSection title="…">`.
4. Червоні бокси помилок (`bg-red-…`/`border-red-…`) → `<p role="alert" className="rounded-md border border-[#d0705c]/50 bg-[#d0705c]/10 px-3 py-2 text-sm text-[#f0b4a6]">`.
5. Емодзі в заголовках прибрати.
6. Таб, у якому хук повідомляє помилку (наприклад, помилки `AbilityListEditor` через `onValidityChange`), отримує `invalid: true`.
7. Нічого не міняти в хуках (`lib/hooks/**`) і в `lib/api/**`.

## Review Focus

- Сабміт форми, коли невалідне нативне поле (`required`, `min`) в неактивному табі → форма перемикається на цей таб і фокусує поле (а не «нічого не відбувається»). Тест у задачі 5.
- Select або Dropdown у HUD-формі чи HUD-діалозі відкривається темним і клікабельним (портал у контейнер усередині `.hud-surface`; у vaul-шиті попап не закривається від кліку «поза шитом»). Тест у задачі 2, браузер — задача 20.
- Видалення вибраного вміння, видалення останнього вміння, додавання кількох вмінь із шаблону → вибір завжди вказує на існуюче вміння або на порожній стан. Тест у задачі 7.
- Зміна слота артефакту зі зброї на не-зброю, коли відкритий таб «Зброя» → активний таб стає «Основне», а не порожній екран. Тест у задачі 14.
- Перейменування HUD-змінної `--muted` не повинно змінити вигляд бою й профілю (той самий колір тексту). Перевірка — grep у задачі 1, браузер — задача 20.

```tsx
"use client";

import type { ReactNode } from "react";

import { Tabs, TabsContent, TabsList, TabsTrigger } from "@/components/ui/tabs";
import { cn } from "@/lib/utils";

export interface HudTab<T extends string = string> {
  id: T;
  label: ReactNode;
  content: ReactNode;
  invalid?: boolean;
}

interface HudTabsProps<T extends string> {
  tabs: HudTab<T>[];
  value: T;
  onValueChange: (id: T) => void;
  header?: ReactNode;
  keepMounted?: boolean;
  contentClassName?: string;
}

export function HudTabs<T extends string>({ tabs, value, onValueChange, header, keepMounted = false, contentClassName }: HudTabsProps<T>) {
  return (
    <Tabs value={value} onValueChange={(v) => onValueChange(v as T)}>
      <div className="sticky top-[env(safe-area-inset-top,0px)] z-20 border-b border-[#3a2e22] bg-[#110e0b]/95 backdrop-blur">
        {header}
        <TabsList className="hud-scroll-x flex h-auto w-full justify-start gap-1 overflow-x-auto rounded-none bg-transparent p-1.5">
          {tabs.map((t) => (
            <TabsTrigger key={t.id} value={t.id} className="profile-tab hud-sc h-10 min-w-fit flex-1 shrink-0 rounded-md px-2.5 text-[13px] text-[#8f8473] data-[state=active]:shadow-none">
              {t.label}
              {t.invalid && <span data-invalid-dot aria-label="є помилки" className="ml-1.5 inline-block h-1.5 w-1.5 rounded-full bg-[#d0705c]" />}
            </TabsTrigger>
          ))}
        </TabsList>
      </div>
      {tabs.map((t) => (
        <TabsContent
          key={t.id}
          value={t.id}
          data-tab-id={t.id}
          forceMount={keepMounted ? true : undefined}
          className={cn("mt-0 px-4 py-3", keepMounted && "data-[state=inactive]:hidden", contentClassName)}
        >
          {t.content}
        </TabsContent>
      ))}
    </Tabs>
  );
}
```

```tsx
"use client";

import { type FormEvent, type ReactNode, useRef, useState } from "react";

import { HudTab, HudTabs } from "./HudTabs";

import { ActionBar } from "@/components/common/ActionBar";
import { cn } from "@/lib/utils";

interface HudFormProps<T extends string> {
  id: string;
  onSubmit: (e: FormEvent<HTMLFormElement>) => void;
  tabs?: HudTab<T>[];
  tab?: T;
  onTabChange?: (tab: T) => void;
  children?: ReactNode;
  actions: ReactNode;
  className?: string;
}

export function HudForm<T extends string>({ id, onSubmit, tabs, tab, onTabChange, children, actions, className }: HudFormProps<T>) {
  const formRef = useRef<HTMLFormElement>(null);

  const [innerTab, setInnerTab] = useState<T | undefined>(tabs?.[0]?.id);

  const active = tab ?? innerTab ?? tabs?.[0]?.id;

  const setActive = (next: T) => {
    setInnerTab(next);
    onTabChange?.(next);
  };

  // the browser cannot focus an invalid control inside a hidden tab, so reveal that tab first
  const onInvalidCapture = (e: FormEvent<HTMLFormElement>) => {
    if (!tabs || !active) return;

    if (formRef.current?.querySelector(`[data-tab-id="${active}"] :invalid`)) return;

    const target = e.target as HTMLElement;

    const owner = target.closest<HTMLElement>("[data-tab-id]")?.dataset.tabId as T | undefined;

    if (!owner || owner === active) return;

    setActive(owner);
    requestAnimationFrame(() => target.focus());
  };

  return (
    <form ref={formRef} id={id} onSubmit={onSubmit} onInvalidCapture={onInvalidCapture} noValidate={false} className={cn("flex flex-col", className)}>
      {tabs && active ? <HudTabs tabs={tabs} value={active} onValueChange={setActive} keepMounted /> : <div className="px-4 py-3">{children}</div>}
      <ActionBar className="mt-auto border-[#3a2e22] bg-[#110e0b]/95 px-4 sm:px-4 sm:pb-4">{actions}</ActionBar>
    </form>
  );
}
```
