## What changes (layout/shape/type; NOT colours)
Use our existing palette tokens (`--hud-*`, `--palette-*`, parchment/frost must work); the prototype's crimson maps to our accent/gold-or-danger tokens as the existing UI does. Do not copy hex values or the grain overlay (tiling noise made seams before; platform background is a separate task).
1. **Header** (`section.head`): banner portrait on the left (portrait in an inset frame hanging on a banner with a pointed bottom edge, "N Level" plate, class crest at the foot); right: one line `Class · Race · Background · Alignment` above a large display name (Cormorant SC), a one-line italic tagline/bio excerpt with a "History" link (switches to the story tab), and on the right the level-up block ("+N points of growth" + one primary button "Distribute"). Top bar in the sheet header: breadcrumb left, DM actions (Master/Edit/Resources) right as quiet text buttons with icons (keep existing actions and permissions).
2. **HUD panel** (`section.panel.hud`): one bordered panel with a 4-column grid: HP cell (label with icon, "Temp N [+]", a thick bar with "274 / 274" inside, below it an amount input and two buttons "− Damage" / "+ Healing" — DM only, players read-only), then AC (shield token), Initiative, Speed cells with icon label, big Oswald number and small unit; a footer strip: Proficiency, To-hit/Spell attack, Hit dice, Passive perception. Keep applyHpChange/useEditResources logic, count-up and ghost-tail motion.
3. **Abilities row** (`#abilities`): six cells in ONE panel, ALWAYS visible above the tabs (not inside a tab): icon + display-font name, big modifier (Oswald, 42px), score in a small plaque below, a bottom row "Saving throw ±N" with a diamond (filled = proficient, outline otherwise; sr-only text), primary ability marked by a top accent line. Clicking rolls the check (existing roll flow); save row rolls the save.
4. **Tabs bar**: an outlined strip (1 px border, radius 4) under the abilities; icon + label per tab, selected = raised cell with accent icon and an accent underline (sliding indicator kept), order: Skills (id `stats`, default), Combat, Magic, Inventory, Traits & languages (id `skills`), Story, Journal (+ system tabs unchanged). On phone: compact horizontal scroll, sticky, one panel at a time. A section caption row ("Skills" display h2 + legend with diamonds + right-aligned hint "tap to roll").
5. **Panels** (see `data-panel` sections in the HTML): Skills — two columns of 40 px rows (diamond, name, ability abbreviation, bonus), passives, languages & proficiencies; Combat — attacks etc. as already built, restyled; Magic — header strip (spell save DC, spell attack, casting ability) and "Spell slots" panel with per-level columns I–IX and diamond cells (filled = available, outline = used), then the spellbook as before; Inventory/Traits/Story/Journal restyled to the same panel language.
6. Shapes: radius 4 px, one border + one soft shadow per panel, bone-coloured numerals; fonts Cormorant SC (titles/names/legend headings), Alegreya (body), Oswald (numbers/HUD). Fonts must be SELF-HOSTED (`next/font/google` is banned: see docs/architecture/platform.md for how existing fonts are loaded; only add Oswald/Cormorant SC/Alegreya weights actually used, check what is already present first).
7. Accessibility/motion bar unchanged: contrast ≥ 4.5:1 text / 3:1 UI on dark, parchment, frost; targets ≥ 40 px; focus rings; not colour-only; reduced-motion safe.
