# WFRP 5e-1: таланти й XP-леджер — план реалізації

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Кроки — чекбокси. Per-task рев'ю немає (feedback-review-cadence): один фінальний Opus-рев'ю на гілку.

**Goal:** гравець/ДМ витрачає XP на advances характеристик, навичок і таланти за прогресивними цінами; сервер валідує, веде леджер, ДМ відкочує останню покупку; таланти діють у бою.

**Architecture:** чисті модулі `wfrp/advancement/` + хук `advancement` у `RuleSystemDefinition` (wfrp-only); операції персонажа `advance`/`advance-undo` через `defineCharacterOperation` (транзакція + `lockCharacters`); таланти = `feats` з `xpCost`/`maxRank`, набуті — `characteristics.talents`, у бій — wfrp-адаптер, що будує ability-групи напряму (choices/`classMode` не чіпаємо).

**Tech Stack:** Next.js 16, Prisma 6 (одна expand-only міграція), Zod, TanStack Query, vitest, next-intl.

**Spec:** `docs/superpowers/specs/2026-11-05-wfrp-5e1-design.md` (читати разом із планом).

### Task 3: Рушій `wfrp/advancement/` + хук системи

**Files:** `wfrp/advancement/{cost,plan,undo,talent-groups,index}.ts`, `lib/utils/rules/systems/types.ts`, `wfrp/index.ts`.

**Interfaces:**
- `advanceCost(kind: "characteristic" | "skill", currentAdvances: number, rules: AdvancementRules): number | null` — `null` на ліміті (`currentAdvances >= max`).
- `type PurchaseRequest = { kind: "characteristic" | "skill" | "talent"; key: string }` (для навички `key` має форму `SKILL_ADVANCE_KEY_RE`: `melee:basic`, `athletics`).
- `type PurchaseError = "INSUFFICIENT_XP" | "AT_LIMIT" | "MAX_RANK" | "UNKNOWN_KEY" | "UNKNOWN_TALENT" | "TALENT_NO_COST"`.
- `planPurchase(input: { characteristics: Characteristics; available: number; request: PurchaseRequest; rules: AdvancementRules; talent?: { id: string; xpCost: number | null; maxRank: number | null }; now: string; id: string }): { ok: true; next: Characteristics; entry: LedgerEntry } | { ok: false; error: PurchaseError }` — чиста, без `Date.now()`/random усередині (час і id приходять ззовні); ледж > 200 → найстаріший запис зрізається.

Невідомий featId — пропускається.
- Системний хук: `RuleSystemAdvancement = { cost; planPurchase; planUndo; availableXp; talentGroups }`, поле `advancement?: RuleSystemAdvancement` у `RuleSystemDefinition`; `WFRP_SYSTEM.advancement = WFRP_ADVANCEMENT`; homm/dnd5e — `undefined`.
