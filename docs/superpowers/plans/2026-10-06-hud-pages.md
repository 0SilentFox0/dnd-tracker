# Пункт 11 — HUD-сторінки й хвости — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Усі не-форменні сторінки — у HUD-стилі напівпрозорими панелями поверх арту розділу; закрити 4 відкриті хвости.

**Architecture:** Нові примітиви `components/hud/page/` (`HudPage`, `HudPanel`, `HudPageHeader`, `HudCard`, `HudTile`, `HudChipTabs`) + CSS у `components/hud/hud.css` (клас `.hud-page`, HUD-акордеони, стани), застосовані до кожної сторінки без зміни даних і поведінки. Хвости — точкові зміни в хуках, маршрутах і view-утилітах бою.

**Tech Stack:** Next.js 16, React 19, Tailwind v4, Radix (shadcn), Prisma, Vitest + Testing Library (happy-dom, `globals: false` → `afterEach(cleanup)`).

**Spec:** `docs/superpowers/specs/2026-10-06-hud-pages-design.md`

## Global Constraints

- Поведінка й дані сторінок не змінюються: ті самі запити, дії, діалоги, тексти кнопок, доступні імена, `aria-pressed` / `aria-current`, DnD юнітів.
- Арт розділу (`BackgroundImage`, шар 75%) лишається. Панелі: `bg-[rgba(17,14,11,.82)]`, рамка `#3a2e22`. Блюр — лише `HudPageHeader` і `Header`.
- Палітра: золото `#c9b37a` / метал `#8a6414 → #e6c25a`, рамка `#4a3c2c`, поле `#1a140f`, текст `#e6dccb` / `#efe5d2`, приглушений `#8f8473`, помилка `#d0705c`, картка `rgba(20,16,12,.85)` з `inset 0 0 0 1px rgba(230,194,90,.25)`.
- 390 px: немає горизонтального скролу, кнопки шапок не обрізаються (`flex-wrap`).
- Друк (`dm/print/*`) не чіпати.
- Жодних нових «магічних» рядків для доменних значень (`lib/constants`). Мінімальні коментарі. Компоненти не імпортують `@/lib/api/*`. Порядок імпортів через `pnpm exec eslint --fix`.
- vitest `globals: false`: у нових тест-файлах, що рендерять більше одного разу, — `afterEach(cleanup)`. happy-dom не підтримує селектор `:invalid`. `next/font` застаблено глобально.
- Кнопки з власним фоном (`bg-…`) і `variant` за замовчуванням у `.hud-page` перефарбуються на золото. Таким кнопкам дай явний `variant` (`outline` / `secondary` / `ghost`) або залиш золото, якщо це головна дія.
- Після кожного блоку: `pnpm test:run && pnpm exec tsc --noEmit && pnpm lint`.

### Рецепт сторінки списку (задачі 6–12)

1. Корінь: `container mx-auto p-4 …` → `<HudPage>` (довідник — `width="md"`).
2. Шапка: `PageHeader` / саморобний `h1` + рядок кнопок → `<HudPageHeader title=… subtitle=… actions={…}>{тулбар/фільтри}</HudPageHeader>`.
3. Shadcn `Card` елемента списку → `<HudCard>` (колір раси чи навику → `accent`, стан → `tone`). Вміст картки й дії не змінюються.
4. Секції сторінки → `HudSection` (`@/components/hud/form`) або `HudPanel`.
5. Акордеони лишаються акордеонами. HUD-вигляд дає CSS із задачі 1, у компонентах прибрати лише конфліктні класи кольору (`bg-card`, `border-gray-*`, `text-primary`, якщо дає рожевий).
6. Жорсткі кольори (`green-*`, `yellow-*`, `gray-*`, `white`) → HUD-палітра.

```tsx
// HudCard.tsx
import { Slot } from "@radix-ui/react-slot";
import type { ReactNode } from "react";

import { cn } from "@/lib/utils";

const TONE = {
  default: "shadow-[inset_0_0_0_1px_rgba(230,194,90,.25)] hover:shadow-[inset_0_0_0_1px_#e6c25a]",
  active: "shadow-[inset_0_0_0_1px_#e6c25a,0_0_12px_rgba(230,194,90,.18)]",
  muted: "opacity-70 shadow-[inset_0_0_0_1px_rgba(230,194,90,.15)]",
} as const;

interface HudCardProps {
  tone?: keyof typeof TONE;
  accent?: string;
  asChild?: boolean;
  className?: string;
  children: ReactNode;
}

export function HudCard({ tone = "default", accent, asChild = false, className, children }: HudCardProps) {
  const Comp = asChild ? Slot : "div";

  return (
    <Comp
      data-tone={tone}
      style={accent ? { borderLeftColor: accent } : undefined}
      className={cn("block rounded-lg bg-[rgba(20,16,12,.85)] p-3 text-[#e6dccb] transition-shadow", accent && "border-l-[3px]", TONE[tone], className)}
    >
      {children}
    </Comp>
  );
}
```

```tsx
// HudChipTabs.tsx
"use client";

import Link from "next/link";
import type { ReactNode } from "react";

import { cn } from "@/lib/utils";

interface ChipItem {
  key: string;
  label: ReactNode;
  href?: string;
  active: boolean;
  onSelect?: () => void;
}

const CHIP = "flex h-8 shrink-0 items-center rounded-full px-3 text-[13px] text-[#8f8473] shadow-[inset_0_0_0_1px_#4a3c2c]";

const ACTIVE = "text-[#ffd9a8] shadow-[inset_0_0_0_1px_#e6c25a,0_0_8px_rgba(230,194,90,.3)]";

export function HudChipTabs({ items, ariaLabel }: { items: ChipItem[]; ariaLabel: string }) {
  return (
    <nav aria-label={ariaLabel} className="hud-scroll-x -mx-1 flex gap-1.5 overflow-x-auto px-1 py-1">
      {items.map((it) =>
        it.href ? (
          <Link key={it.key} href={it.href} aria-current={it.active ? "page" : undefined} className={cn(CHIP, it.active && ACTIVE)}>
            {it.label}
          </Link>
        ) : (
          <button key={it.key} type="button" aria-pressed={it.active} onClick={it.onSelect} className={cn(CHIP, it.active && ACTIVE)}>
            {it.label}
          </button>
        ),
      )}
    </nav>
  );
}
```
