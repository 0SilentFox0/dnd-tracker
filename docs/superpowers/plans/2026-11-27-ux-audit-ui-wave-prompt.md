Пам'ять: `project-ux-audit-2026-11-27`.
2. **Reuse/інвентаризація:** де визначені токени кольорів/палітр (tavern, parchment), шрифти (self-hosted, `next/font/google` заборонено), `HudButton`/`components/ui/button`, `Badge`/чипи, `HudChipTabs`, скелетони, порожні стани, контейнер сторінок. Випиши, що перевикористовуємо, що зливаємо.
3. **Spec (Opus-субагент, `superpowers:brainstorming`):** `docs/superpowers/specs/2026-11-27-ux-ui-polish-design.md` — конкретні токени й правила:
   - 7.1 контраст: `faint` Таверна `#6b6156`→`#8c8272`, Пергамент `#a29482`→`#7d705f` (або `faint` заборонено для тексту), `accent-2` `#8f7a3f`→`#a38d4c`, disabled = opacity .5 від повного кольору + `cursor: not-allowed`; ціль ≥4.5:1 для тексту;
   - 7.2 типошкала `--fs-*` 12/14/16/18/22/28/40, мінімум 12px (HUD бою, картки `/battles/new`, mono-мітки), описи/довідка 14px; Cormorant SC < 14px → Alegreya 600;
   - 7.3 три родини (Alegreya, один display — Cormorant SC або Alegreya SC, Oswald для чисел), прибрати EB Garamond, Alegreya Sans;
   - 7.4 кнопки sm 32 / md 40 / lg 48, touch 44 на мобільному; радіуси `--r-sm 4 / --r-md 8 / --r-lg 12 / --r-pill`;
   - 7.5 єдиний `.page` max-width 1200 + padding 24/16 (wide лише бій/мапи), однаковий фон (карта + затемнення) на сценарії й вході;
   - 7.12 чипи/бейджі: золотий — лише роль, outline — метадані, сірий — NPC; висота 24, радіус 4; одна мова вкладок;
   - 7.7 HP-смуга → `--hud-hp` з градієнтом, текст ≥5:1; 7.8 картки без портрета 120–140px + іконка класу; 7.9 Пергамент: сепія-фон + grain, disabled/placeholder; 7.10 порожні стани/404 з ілюстрацією `book-*`; 7.11 скелетони у формі контенту з shimmer; 7.13 лендинг: reveal цілим блоком + `prefers-reduced-motion`; 7.14 мікрошрифти шапки/дашборда, підписи «До бою»/«Показ» на мобільному;

   Питання власнику — по одному, з рекомендацією (напр. який display-шрифт лишити). Spec — лише рішення й значення, без коду.
4. **Ratchet/гард:** додати перевірку, що не дає повернути дрібний текст і довільні значення (напр. тест/скрипт: заборона `text-[9px|10px|11px]`, довільних `rounded-[..]` і висот кнопок поза шкалою в `components/**`, `app/**`; baseline-ratchet за зразком `ratchets/`, що лише зменшується).
5. **Виконання** (subagent-driven, імплементери Sonnet, 2–3 суміжні пункти на агента, тести пишуть, не запускають): спершу токени/шкали/примітиви (7.1–7.4, 7.12), потім сторінки (7.5–7.11, 7.13–7.14, 6.6). Міняти примітиви, а не кожну сторінку окремо, де можливо.

Живий прогін: `pnpm build:local` + `next start -p 3000` (не `next dev`), `RATE_LIMIT_ALLOW_MEMORY=1`; власник логіниться у вікні розширення; перевірка — субагентом зі скороченими скріншотами.
