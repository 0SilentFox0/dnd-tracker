# Специфікації та плани

Тут лежать лише **активні** специфікації (`specs/`) і плани (`plans/`). Коли фіча злита в `main`, її файли переносяться через `git mv` у `docs/archive/superpowers/` в тому ж коміті злиття.

Зараз активне: [план виправлень імпорту Obojima](plans/2026-10-28-obojima-import-fixes.md); у `specs/assets/` — скріншоти й макети карти світу, на які посилаються архівні специфікації.

Архів ([`docs/archive/superpowers/`](../archive/superpowers/)) містить завершену роботу, зокрема весь епік «Конструктор кампаній» (етапи 1–6, refactor S1–S10, pre-merge ревю, HOMM-шлюз, [handoff](../archive/superpowers/constructor-handoff.md)). Він відображає рішення на момент написання, тому код не обов'язково досі їм відповідає. Актуальний опис підсистем дивіться в `docs/architecture/`, поточну роботу — в `docs/STATUS.md`.
