# Специфікації та плани

Тут лежать лише **активні** специфікації (`specs/`) і плани (`plans/`). Коли фіча злита в `main`, її файли переносяться через `git mv` у `docs/archive/superpowers/` в тому ж коміті злиття.

Архів містить старі рішення, тому код не обов'язково досі їм відповідає. Актуальний опис підсистем дивіться в `docs/architecture/`, поточну роботу — в `docs/STATUS.md`.
