**Обмеження**

- Радіус `3.35544e+07px` = pill (`rounded-full`), рахується як один радіус.
- Бій у Parchment: усі вузли мають градієнтний фон (`.battle-hud`), контраст не рахується (`skippedGradient` = усі вузли).
- Контраст рахується по `color` і ефективному фону предків, без урахування `opacity` предків і псевдоелементів (`body::after`).

**Скорочення:** rad = кількість різних радіусів (pill враховано), btn = кількість різних висот кнопок (значення), `<12`/`=12` = частка символів, fails = кількість/перевірено, grad = `skippedGradient`.
