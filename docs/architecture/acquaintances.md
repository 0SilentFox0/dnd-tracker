# Знайомства

- Таблиці (RLS увімкнено): `acquaintances`, `acquaintance_entries` (журнал), `acquaintance_notes` (одна на автора: `@@unique(acquaintanceId, authorUserId)`) + `Campaign.acquaintancesEnabled`. `sourcePageId`/`pageId` — рядки без FK: секції живуть у JSON сторінки сценарію, видалення сторінки чи секції не стирає знайомство, воно лишається прихованим (DM бачить його з позначкою). `kind`: `micro` або `character`; для `character` ім'я й аватар беруться з персонажа, а `name`/`avatarUrl` самого знайомства — запас, якщо персонажа видалено.
- Видимість — чиста функція `lib/utils/acquaintances/visibility.ts` (`viewAcquaintances`, `isAcquaintanceRevealed`) над `PlayedLookup` з `loadPlayedSections` (`lib/server/scenario/page-store.ts`). Гравець бачить знайомство, якщо `acquaintancesEnabled` і секція-джерело зіграна; запис журналу — якщо зіграна його секція. DM бачить усе, приховане — з `hidden: true`. Фільтр лише на сервері (`lib/server/acquaintances/store.ts`); вимкнений перемикач → 403 `errors.acquaintancesDisabled` для гравців.
- Нотатки: PUT upsert власної (порожній текст видаляє); гравець бачить лише свою, DM — усі з іменами авторів. PUT до прихованого знайомства від гравця → 404 без імені.
- Розкриття → сповіщення: дві точки запису «зіграно» — `section-handler.ts` (PATCH секції) і `writeScenarioContent` (збереження редактора, restore, AI/MCP) — викликають `notifyRevealForContentChange` (`lib/server/acquaintances/reveal.ts`): діф `newlyPlayedSections(before, after)` → `afterContentCommit` → `notifyAcquaintanceReveal` (ковтає помилки й логує) → `notifyCampaignPlayers` типу `acquaintance`. Нові записи журналу розкритого знайомства теж шлють сповіщення. Повторне «зіграно» без зміни не шле; ввімкнення перемикача пізніше сповіщень не шле. Рядок сповіщення один на `userId+type+refId` (повторна подія знову робить його непрочитаним).
- Редактор: mention-тип `acquaintance` (`MENTION_TYPES`, `mentionHref` → `/campaigns/<c>/acquaintances?focus=<id>`), кнопка «Знайомство» і `AcquaintanceDialog` (`components/scenario/editor`). Повторне виділення вставляє наявний чип.
- Клієнт: `lib/api/acquaintances.ts` → `lib/hooks/acquaintances`; таб `app/campaigns/[id]/acquaintances` (серверна сторінка з `PrefetchedQuery`, redirect для гравця при вимкненому перемикачі); плитка «Знайомства» в `lib/constants/campaign-dashboard.ts` і `NOTIFICATION_TILE_TYPES`.
- **Як додати поле:** `prisma/schema.prisma` + expand-only міграція → `lib/schemas/acquaintances.ts` → `AcquaintanceRecord`/`viewAcquaintances` і `types/acquaintances.ts` → діалог і картка.
