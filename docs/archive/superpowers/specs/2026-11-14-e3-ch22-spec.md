# E3 Ч22 — specification (reuse + scope)

Source of decisions: `docs/superpowers/plans/2026-11-14-e3-plan.md`, section Ч22 (Р22.1–Р22.6). This file only records reuse and execution rules.

## Reused (not rewritten)
- `RuleSystemConditionSet` / `conditionSet` slot (`lib/utils/rules/systems/types.ts`), `ruleSystemOf`, `assertEffectsInComposition` (`lib/server/content/traits-guard.ts`), `parseBody`/`errorResponse`, `lib/constants/api-errors.ts`.
- `RuleSystemActions` slot, `SystemServer.schemas` (Ч11), `SystemSlot`/`defineSlot`, `useCampaignSystem`.
- Pipeline test helpers: `lib/__tests__/helpers/{system-contract,composition-matrix,install-entries}.ts`; existing d6pool fixture and `lib/__tests__/d6pool-battle.test.ts`.
- Ratchet: `lib/__tests__/system-literals.test.ts` (`LEAK_NAMES`).

## New (why)
- `systems/d20/rules/{conditions/keys,actions/*,attack/cunning-strike,magic/*}` — d20-only vocabulary/mechanics leaving core.
- `allConditionKeys()` helper (registry) — the only core place that unions all systems' keys (template editor, no campaign).
- Hooks `combat.attack.hitRiders`, `magic.attackRoll`, `magic.saveCrit`, `combat.zoneAttack` — a base without them = no spell attack roll.

## Execution rules
- Packages A (conditions) ∥ B (actions+cunning-strike) → C (spell hooks) → D (contract test + docs). Agents write tests, do NOT run the full suite; allowed: `pnpm exec tsc --noEmit`, `pnpm test:related <files>`, `pnpm cycles`, `pnpm exec eslint --fix <touched>`.
- Shared `lib/utils/rules/systems/types.ts`: use Edit only on your own interfaces; never revert others' edits.
- Agents do NOT commit, push, stash or switch branches; the controller commits.
- No Prisma migrations. Stored keys (`blinded`, `dash`, …) never change.
