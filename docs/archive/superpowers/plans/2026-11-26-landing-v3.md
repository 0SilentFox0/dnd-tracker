# Landing v3 (prod) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Лендінг у дизайні платформи (Ч8a), коректний на 4K, з паралаксом (скрол + курсор), новими блоками, свіжими скрінами EN/UK, legal-сторінками, аналітикою і видаленням акаунта.

**Architecture:** Статичні сторінки `/` і `/uk` лишаються `○`. Паралакс: CSS scroll-timeline + один маленький клієнтський компонент для `--mx/--my`. Legal: статичні серверні сторінки на `getTranslator(locale, 'legal')`. Видалення акаунта: тонкий `DELETE /api/account` → сервіс `lib/server/account/` з гардом шаблонів, Prisma-транзакцією, потім Storage і Supabase admin.

**Tech Stack:** Next.js 16 App Router, React 19, Tailwind, next-intl (`use-intl/core`), Prisma 6, Supabase Auth admin, `@vercel/analytics`, Vitest (+ happy-dom), Playwright-скрипт скрінів.

**Spec:** `docs/superpowers/specs/2026-11-26-landing-v3-design.md`

## Global Constraints

- Worktree `../dnd-tracker-landing`, гілка `feat/landing-v3` (Ч1–Ч4); Ч5 — гілка `feat/account-delete` від `feat/landing-v3` (або main), окремий worktree `../dnd-tracker-account`. Основну папку не чіпати.
- Root layout не читає cookies/headers; `/`, `/uk` і legal-сторінки лишаються статичними (`○` у `next build`).
- Жодних бібліотек анімації/WebGL; паралакс — CSS + ≤ 1 КБ клієнтського JS.
- Без жаринок/частинок/глоу; золото лише для CTA/акцентів; контраст тексту ≥ 4.5:1; цілі ≥ 40 px.
- `prefers-reduced-motion: reduce` → усе статичне; `(pointer: coarse)` → без курсорного паралаксу.
- Тексти лише в `messages/{en,uk}/*.json`; назва — `{brand}`; кирилиця в коді заборонена (ESLint), коментарі англійською й мінімальні.
- WFRP/Warhammer на лендінгу не згадується — лише «Grim d100».
- Індексацію (`SITE_INDEXING`) не вмикати.
- Агенти-виконавці НЕ запускають повний `test:run`; лише `pnpm test:run <file>` / `pnpm test:related`; повний прогін — один раз наприкінці частини.
- Lint: `pnpm exec eslint --fix <files>`; цикли: `pnpm cycles`.
- Живі прогони — `next start` (не `next dev`), порт 3120, окрема локальна БД.

## Review Focus

1. **Lighthouse mobile після появи фон-шару:** LCP на 4G не гірше ~2.5 с — preload 2k + `fetchpriority=high`, 4k не вантажиться на ≤ 1920 px (тест у Task 1: `<link rel=preload>` має `imageSrcSet`/media для 2k).
2. **Браузер без scroll-timeline (Firefox):** сторінка виглядає як статична, нічого не зсунуто/не обрізано — фолбек у `@supports` (перевірка в Task 1 на рівні CSS-рядка + живий прогін Firefox, якщо доступний).
3. **Сторінка з відкритим застосунком у тій самій вкладці:** `PointerParallax` знімає слухач і rAF при unmount (тест Task 1).
4. **Видалення акаунта ДМа, у кампанії якого грає інший гравець:** кампанія зникає, у гравця вона просто пропадає зі списку без 500 (тест Task 11: членство іншого користувача видалено каскадом, його `users` цілий).
5. **Повторний DELETE після часткового збою Supabase:** відповідь 200, не 500 (тест Task 11 «ідемпотентність»).

**Interfaces:**

**Рішення:**
- `ld-bg`: `position: fixed; inset: -6%` (запас під зсув), `background: image-set(url(/bg/vey-strait-2k.webp) 1x)`, `@media (min-width: 1921px)` → 4k; `transform: translate3d(calc(var(--mx,0)*-12px), calc(var(--my,0)*-12px), 0)`, плюс `@supports (animation-timeline: scroll())` → `animation: ld-bg-scroll linear both; animation-timeline: scroll(root)` (`to { translate: 0 -8% }` — окрема властивість `translate`, щоб не конфліктувати з `transform`).
- `ld-fog`: два `radial-gradient` з низькою opacity, `@keyframes ld-fog-drift` 50 с, курсор ±24 px.
- `ld-light`: `radial-gradient(600px at calc(50% + var(--mx,0)*30%) calc(40% + var(--my,0)*30%), rgba(230,194,90,.10), transparent 70%)`.
- `ld-vignette`: як `body::after` у `app/globals.css` (rgba(0,0,0,.72) по краях, прозоріше в центрі hero).
- Усе в `@media (prefers-reduced-motion: no-preference)`; поза ним — лише статичні шари.
- Preload: у `buildLandingMetadata` не можна; додати `<link rel="preload" as="image" href="/bg/vey-strait-2k.webp" fetchPriority="high" media="(max-width: 1920px)">` прямо в `LandingBackdrop` (React 19 піднімає `<link>` у head).
- `PointerParallax`: якщо `matchMedia('(pointer: coarse)')` або `matchMedia('(prefers-reduced-motion: reduce)')` → нічого не підписує. Інакше `pointermove` (passive) зберігає ціль, rAF-цикл lerp 0.08 до цілі, зупиняє rAF, коли різниця < 0.001; `visibilitychange` hidden → cancel rAF. Cleanup знімає все й видаляє змінні.
- Hero більше не має власного фонового градієнта (`Hero.tsx` рядок з `bg-[radial-gradient…#0b0908]` прибрати) — фон спільний.
