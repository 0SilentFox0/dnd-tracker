# Карти бою Ч1a — ребра для квадрата й гекса: план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** стіни, ґрати й двері працюють на гекс-карті так само, як на квадратній (рух, видимість, вогонь, туман, шаблони, поштовх, редактор, рендер). Квадратні дані на проді не змінюються.

**Architecture:** новий чистий модуль `lib/utils/battle/grid/edge-keys.ts` знає геометрію ребер обох сіток. `walls.ts`/`edges.ts` делегують у нього; `edgeBlocks`/`cellsConnected` беруть сітку з `gridOf(map)`, тому більшість споживачів (path, sight, shadowcast, template, line-of-fire, adjacency, opportunity, chain) не змінюються — їх покривають гекс-тести. Далі: туман, поштовх, двері, зберігання chunks, guard'и, SVG-рендер і редактор.

**Tech Stack:** TypeScript strict, Vitest, React 19 SVG, Zod.

**Spec:** `docs/superpowers/specs/2026-11-26-map-art-ch1-foundation-design.md` (розділ 2, перевірка — розділ 6). Епік: `docs/superpowers/specs/2026-11-26-map-art-epic-design.md`.

**Гілка / worktree:** `feat/map-art`, `../dnd-tracker-mapart`. Усі шляхи нижче — відносно цього worktree.

## Global Constraints

- Квадратний ключ ребра не змінюється: `x:y:e` / `x:y:s`. Гекс-ключ: `x:y:n` / `x:y:ne` / `x:y:se`.
- Квадратні edge-chunks на проді (128 байт, без заголовка) читаються й пишуться без змін.
- `maze` лишається лише для квадрата; guard на `m.maze` для гекса залишається.
- Тайли на гексі лишаються забороненими (`BATTLE_MAP_HEX_SQUARE_ONLY` у `tiles/route.ts` не чіпаємо); у 1a знімаємо guard'и лише для walls/bars/doors.
- Нові виклики grid-aware функцій — з явною сіткою через `gridOf(...)` (ratchet `lib/__tests__/grid-calls.test.ts`, `ratchets/grid-square-only.json` лише зменшується).
- `lib/utils` не імпортує `lib/server`; імпорти `@/lib/...`; цикли перевіряє `pnpm cycles`. `edge-keys.ts` не імпортує `layout.ts` (той імпортує `walls.ts`, буде цикл).
- Коментарі мінімальні, англійською. Тексти UI — лише в `messages/{uk,en}/*.json`.
- **Тести (правило власника):** агенти SDD пишуть тести, але не запускають suite; дозволено лише `pnpm exec tsc --noEmit` і `pnpm exec eslint --fix <touched files>`. Один повний прогін — у Task 9.

**Рішення:**
- Токени сторін двох сіток не перетинаються, тож ключ сам каже, якій сітці належить (`edgeGridOf`). `parseEdge` не потребує сітки; `edgeOnGrid` — для валідації.
- `CUBE_DIRS` у `hex.ts` у порядку `[se, ne, n, nw, sw, s]` (перевірено через `hexCenter`). Вершини `hexVertices`: 0 — схід, 1 — низ-праворуч, 2 — низ-ліворуч, 3 — захід, 4 — верх-ліворуч, 5 — верх-праворуч. Ребра: `n` = v4–v5, `ne` = v5–v0, `se` = v0–v1, `s` = v1–v2, `sw` = v2–v3, `nw` = v3–v4.
- `UNIT` береться як `2 * HEX_R` (не з `layout.ts` — буде цикл).

Код (неочевидний — подаю повністю):
```ts
import { CUBE_DIRS, cubeStep, fromCube, HEX_R, hexVertices, toCube } from './hex';

import type { GridKind, GridPoint } from '@/types/battle-grid';

const UNIT = 2 * HEX_R;
const SQUARE: readonly EdgeSide[] = ['e', 's'];
const HEX: readonly EdgeSide[] = ['n', 'ne', 'se'];
const HEX_DIR_INDEX: Record<HexDir, number> = { se: 0, ne: 1, n: 2, nw: 3, sw: 4, s: 5 };
const HEX_OPPOSITE: Record<'s' | 'sw' | 'nw', HexSide> = { s: 'n', sw: 'ne', nw: 'se' };
const HEX_VERTS: Record<HexSide, [number, number]> = { n: [4, 5], ne: [5, 0], se: [0, 1] };

const hexStep = (p: GridPoint, dir: HexDir): GridPoint =>
    fromCube(cubeStep(toCube(p), CUBE_DIRS[HEX_DIR_INDEX[dir]]));

export const edgeSidesOf = (grid: GridKind) => (grid === 'hex' ? HEX : SQUARE);
export const formatEdge = (c: GridPoint, side: EdgeSide) => `${c.x}:${c.y}:${side}`;

export function edgeGridOf(key: string): GridKind | null {
    const side = key.split(':')[2];
    if (SQUARE.includes(side as EdgeSide)) return 'square';
    if (HEX.includes(side as EdgeSide)) return 'hex';
    return null;
}

export function parseEdge(key: string): EdgeParts | null {
    const [xs, ys, side] = key.split(':');
    const grid = edgeGridOf(key);
    const a = { x: Number(xs), y: Number(ys) };
    if (!grid || !Number.isInteger(a.x) || !Number.isInteger(a.y)) return null;
    const b = grid === 'square'
        ? side === 'e' ? { x: a.x + 1, y: a.y } : { x: a.x, y: a.y + 1 }
        : hexStep(a, side as HexDir);
    return { a, b, side: side as EdgeSide, grid };
}

export function canonicalEdge(grid: GridKind, cell: GridPoint, dir: SquareDir | HexDir): string {
    if (grid === 'square') {
        if (dir === 'e' || dir === 's') return formatEdge(cell, dir);
        return dir === 'w'
            ? formatEdge({ x: cell.x - 1, y: cell.y }, 'e')
            : formatEdge({ x: cell.x, y: cell.y - 1 }, 's');
    }
    const d = dir as HexDir;
    if (d === 'n' || d === 'ne' || d === 'se') return formatEdge(cell, d);
    return formatEdge(hexStep(cell, d), HEX_OPPOSITE[d]);
}

export function edgeKeyBetween(grid: GridKind, a: GridPoint, b: GridPoint): string | null {
    const dirs: readonly (SquareDir | HexDir)[] =
        grid === 'hex' ? ['n', 'ne', 'se', 's', 'sw', 'nw'] : ['n', 'e', 's', 'w'];
    for (const dir of dirs) {
        const n = grid === 'hex'
            ? hexStep(a, dir as HexDir)
            : { x: a.x + (dir === 'e' ? 1 : dir === 'w' ? -1 : 0), y: a.y + (dir === 's' ? 1 : dir === 'n' ? -1 : 0) };
        if (n.x === b.x && n.y === b.y) return canonicalEdge(grid as never, a, dir as never);
    }
    return null;
}

export function edgeSegment(grid: GridKind, key: string): [Point, Point] {
    const e = parseEdge(key);
    if (!e || e.grid !== grid) throw new Error(`edge ${key} is not a ${grid} edge`);
    if (grid === 'hex') {
        const v = hexVertices(e.a);
        const [i, j] = HEX_VERTS[e.side as HexSide];
        return [v[i], v[j]];
    }
    const { x, y } = e.a;
    return e.side === 'e'
        ? [{ x: (x + 1) * UNIT, y: y * UNIT }, { x: (x + 1) * UNIT, y: (y + 1) * UNIT }]
        : [{ x: x * UNIT, y: (y + 1) * UNIT }, { x: (x + 1) * UNIT, y: (y + 1) * UNIT }];
}
```
`edgeCellsOf` — `[a, b]` з `parseEdge` (кидає `Error`, якщо сітка не та). `edgesOfCell` — `canonicalEdge` для кожного з 4/6 напрямків. `edgeOnGrid` — `edgeGridOf(key) === grid && parseEdge(key) !== null`. Перевантаження `canonicalEdge` прибрати, якщо TS не дає їх зробити чисто — тоді один підпис `(grid, cell, dir: SquareDir | HexDir)`.
