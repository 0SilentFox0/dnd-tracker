# Таблиця росту героїв і баланс архетипів (2026-10)

Повертається з `pnpm hero-growth-report` (`scripts/hero-growth-report.ts`), локальна БД, кампанія «SIM: баланс бібліотеки». Клітинка в таблицях по расах: `HP / ближній / дальній / магія`.

**Припущення таблиці.** Герой будується в пам'яті через `createBattleParticipantFromCharacter`, без навичок, артефактів, інвентаря. Основна характеристика колонки = 14 (СИЛ для ближнього, СПР для дальнього, ІНТ для магії), решта 10, ВИТ 12. Ближній/дальній — середня шкода атаки зі зброєю 1d8 (`averageAttackDamage`, бонус влучання 0); магія — `computeSpellPower` для закляття «8 кубиків» із середніми значеннями кубиків за рівнем героя. Це базова лінія: расові «Стилі бою» входять, навички й артефакти — ні.

## Баланс бою до / після

«До» — останній зафіксований прогін на `main` (`docs/reports/2026-10-08-units-balance.md`, `--runs=12`, герої без архетипів: коефіцієнти ДМ = 1, HP за старою формулою). «Після» — `pnpm balance-library --runs=6 --levels=3,6,10`, одноразово, збірки `martial`→Воїн, `caster`→Маг, `leader`→Лучник (ціль: ±15 п. п.). Прогін зроблено після корекцій; при 6 прогонах шум ±7–10 п. п. на рівень.

| Рівень | До | Після | Різниця |
|---|---|---|---|
| L3 ↔ T1 | 71 % | 86 % | +15 п. п. |
| L6 ↔ T4 | 84 % | 90 % | +6 п. п. |
| L10 ↔ T7 | 91 % | 99 % | +8 п. п. |

По партіях (перемоги / бої, після; до по партіях не фіксували):

| Партія | L3 | L6 | L10 |
|---|---|---|---|
| mixed | 74 % | 95 % | 98 % |
| martial | 100 % | 76 % | 100 % |
| caster | 86 % | 100 % | 100 % |
| leader | 83 % | 88 % | 98 % |

Висновок: рівні в межах 15 п. п. (L3 рівно на межі, L10 99 % — стеля), героям стало легше, бо в Воїна/Лучника додались расові «Стилі бою» й архетипний HP. Для L3 при 6 прогонах різниця на межі шуму; множники чесного балансу (`hpMultiplier`/`damageMultiplier`) вирівнюють ворогів до сили партії, тож додатковий нахил на L10 — слабкість формули, а не архетипів. Окремий прогін до корекцій відсотків не робився (один прогін за вказівкою).
